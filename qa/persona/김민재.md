# 김민재

종중 일에 시간을 많이 쓰지 않는 종중원. 디지털 사용은 능숙하지만 관심과 신뢰가 낮아 연락이 닿지 않는 상태로 남기 쉽다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 46세 |
| 종중 역할 | 일반 종중원, 최근 모임 참여가 적음 |
| 생활 | 타 지역에서 교대 일정으로 근무 |
| 참여도 | 중요 토지 안건에는 의견이 있지만 평소 공지는 잘 확인하지 않음 |
| 디지털 사용 | 스마트폰과 인증 서비스에 익숙하다. 낯선 서비스 설치와 반복 알림을 싫어한다. |
| 서비스 접근 | 연락처 확인이 필요한 명부 항목. 연락 실패를 자격 상실로 처리하지 않는다. |

## 현재 행동과 불편

전화번호를 바꿨지만 종중 명부는 수정하지 않았다. 기존 연락처로 안내를 보낸 운영진은 공지가 끝났다고 생각할 수 있다. 새로운 번호로 안내를 받더라도 발신자가 누군지, 개인정보를 왜 요청하는지 알 수 없으면 링크를 누르지 않는다.

매번 모임 소식이 오면 알림을 꺼두지만 토지 처분 같은 중요한 안건을 뒤늦게 아는 것은 싫다. 낮은 참여도를 동의나 포기로 해석하면 반발할 가능성이 크다.

## 목표와 도입 조건

- 안내가 누구에게서 왔고 어떤 안건인지 확인한 뒤 접근한다.
- 연락처 변경과 본인 명부 연결을 안전하게 확인한다.
- 자신의 미응답이 찬성이나 참석으로 기록되지 않는다.
- 중요한 안건과 일반 공지를 구분해 볼 수 있으면 참여를 검토한다.

대표 발언: “연락이 안 됐다고 제가 동의한 건 아니죠. 먼저 명부에 어떤 연락처가 있는지 확인해야 해요.”

## 서비스 사용 장면

총무가 기존 번호의 발송 실패를 확인하고 적절한 다른 연락 경로로 연락처를 확인한다. 김민재는 안내의 출처와 안건을 확인한 뒤 자신의 명부 항목 연결을 요청한다. 새 연락처를 등록해도 이전 회의의 발송 이력을 지우지 않는다.

알림 분류나 세부 수신 설정은 후속 UX 요구로 조사한다. 실제 소집 절차를 임의로 생략하는 기능으로 만들지는 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 오래된 연락처 | 발송 실패가 보이고, 실패를 안내 성공·불참·자격 상실로 처리하지 않는다. |
| 연락처 변경 | 확인 절차 없이 낯선 계정을 명부에 연결하거나 종중 자료를 열어주지 않는다. |
| 늦은 응답 | 미응답 상태와 뒤늦게 남긴 의견의 시점을 구분하며 과거 결과를 조용히 덮어쓰지 않는다. |

## PRD 연결

P0의 연락처 확인 상태, 안내 결과, 미응답, 명부와 계정의 분리를 검증한다. 관심 부족과 사용 능력 부족을 다른 문제로 다룬다.
