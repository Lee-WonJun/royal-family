# 김순자

앱보다 전화와 종이 자료가 편한 종중원. 서비스에 가입하지 않아도 안내 대상에서 빠지지 않고 자신의 의사가 정확히 기록되기를 바란다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 81세 |
| 종중 역할 | 일반 종중원, 오래전부터 모임 참여 |
| 생활 | 종중 소재지 인근 거주 |
| 참여도 | 대면 모임은 가능하면 참석하고 중요한 안내는 전화로 듣는다. |
| 디지털 사용 | 통화 중심으로 휴대전화를 사용한다. 문자 링크, 비밀번호, 모바일 문서 확인은 어렵다. |
| 서비스 접근 | 초기에는 계정 없이 명부에서 관리. 도움을 주는 사람의 계정과 본인의 명부 항목을 구분한다. |

## 현재 행동과 불편

문자가 와도 길면 읽기 어렵고 링크를 열지 않는다. 회의 안내를 가족이나 다른 종중원에게 전해 듣기도 해 장소와 시간이 정확하지 않을 때가 있다. 대신 익숙한 총무와 직접 통화하면 참석 여부나 질문을 분명히 말한다.

온라인에 가입하지 않았다는 이유로 회의 내용을 못 듣거나 자신이 무응답자로만 기록되는 것은 원하지 않는다. 다른 사람이 휴대전화를 대신 만져준 것과 본인의 의견을 대신 결정한 것도 다르다고 생각한다.

## 목표와 필요한 지원

- 전화나 종이 안내로도 안건과 일정을 전달받는다.
- 본인이 말한 참석 응답을 누가 언제 기록했는지 남긴다.
- 큰 글씨로 출력한 자료를 받아 읽는다.
- 도움을 받았다는 이유만으로 대리 참석·의결을 한 것으로 처리되지 않는다.

대표 발언: “문자만 보내면 몰라요. 전화로 설명해주고 제가 한 말을 그대로 적어주세요.”

## 서비스 사용 장면

총무가 문자 미확인 상태를 보고 전화로 회의를 안내한다. 김순자가 참석할 수 있다고 답하면 총무는 안내 방식, 기록자와 확인 근거를 남긴다. 회의 당일에는 실제 참석을 별도로 확인한다. 총무가 응답을 입력했다고 김순자가 웹에서 읽거나 직접 입력한 것으로 표시하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 미가입 상태 | 계정이 없어도 명부와 회의 대상 목록에 남고, 안내 실패·미확인을 담당자가 찾을 수 있다. |
| 전화 응답 기록 | 총무의 입력과 본인의 웹 입력을 구분하며 수동 기록의 방식·시각·근거가 남는다. |
| 도움과 위임 구분 | 단순한 사용 지원이 위임 자료나 대리권 승인으로 자동 처리되지 않는다. |
| 종이 자료 확인 | 출력한 문서의 글자·페이지·상태 표시를 읽고 어떤 안건인지 설명할 수 있다. |

## PRD 연결

P0의 미가입자 명부, 수동 안내, 실제 참석, PDF 출력과 접근 지원을 검증한다. 가족·지원자가 사용하는 계정에 본인의 권한을 자동으로 넘기지 않는 흐름이 필요하다.
