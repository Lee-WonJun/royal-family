# 김도윤

멀리 살지만 종중 운영을 디지털로 바꾸는 데 관심이 있는 종중원. 편의 기능을 빨리 도입하고 싶어 하므로 자동화의 한계도 이해해야 한다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 33세 |
| 종중 역할 | 일반 종중원, 초기 서비스 사용을 돕는 자원자 |
| 생활 | 타 지역에서 IT 관련 직장 근무 |
| 참여도 | 대면 모임은 드물게 참석하지만 자료를 보며 의견을 내고 싶음 |
| 디지털 사용 | 웹 서비스, 파일 공유, 모바일 인증에 익숙함 |
| 서비스 접근 | 일반 종중원 권한. 기술 지원 역할만으로 관리자나 대리 의결 권한을 주지 않는다. |

## 현재 행동과 불편

회의가 끝난 뒤 가족·친족의 요약을 전해 듣는 경우가 많다. 결정한 이유와 원래 안건을 직접 확인하기 어렵다. 파일을 온라인에 모으거나 회의 내용을 자동으로 정리하면 해결될 것이라고 생각하지만, 실제 종중 규약과 절차에는 익숙하지 않다.

운영을 돕겠다는 이유로 총무 계정이나 전체 자료를 요청할 가능성이 있다. 도움을 주는 범위와 개인정보를 열람하는 범위를 나눌 필요가 있다.

## 목표와 도입 조건

- 회의 전 자료를 읽고 참석 여부와 의견을 남긴다.
- 토지 자료의 마지막 확인일과 변경 정보를 직접 확인한다.
- 필요할 때 실무를 도와도 다른 사람의 계정을 공유하지 않는다.
- 자동화가 지원하지 않는 업무와 아직 검토 중인 기능을 구분한다.

대표 발언: “등기 알림이 없으면 아무 일도 없는 건가요? 마지막으로 확인한 날짜도 보여주세요.”

## 서비스 사용 장면

모바일 알림에서 토지 상세를 열고 최신 자료의 확인일을 본다. 확인 지연 상태라면 변동 없음으로 해석하지 않고 담당자에게 확인을 요청한다. 회의에 참석하기 어려운 경우 P0에서는 참석 응답과 의견을 남긴다. 원격 전자 의결은 별도 검토가 필요한 P1 기능으로 이해한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 등기 확인 지연 | 마지막 성공 시점과 실패·미확인 상태를 찾고, 알림이 없다는 이유로 변동이 없다고 단정하지 않는다. |
| 기술 지원 요청 | 자신의 계정에서 지정된 지원 업무만 수행하며 총무의 비밀번호나 전체 운영 권한을 받지 않는다. |
| 자동 전사 기대 | P1 전사 초안에서 이름·금액·결론의 확인이 필요하다는 점을 이해하고 생성 내용을 확정본으로 공유하지 않는다. |

## PRD 연결

P0의 원거리 열람, 참석 응답, 등기 확인 상태와 최소 권한을 검증한다. P1 자동 확인·STT에 대한 기대를 조사하되 이미 가능한 기능으로 제시하지 않는다.
