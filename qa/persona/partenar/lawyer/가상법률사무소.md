# 가상법률사무소

변호사 한 명과 사무 직원이 함께 종중의 토지 관련 상담을 처리하는 소규모 법률사무소. 자료 접수와 보완 요청은 직원이 맡고, 법률 검토와 최종 의견은 담당 변호사가 맡는다.

단체명·인원·업무 경험과 대표 발언은 QA를 위한 가상 설정이다. 실제 사무소나 사건과 관계없다. 외부 전문가가 조직 단위로 참여하는 흐름을 검증한다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 법률사무소 |
| 구성 | 변호사 1명, 사무 직원 2명이라는 가상 설정 |
| 주된 분야 | 종중 토지 처분 상담, 회의·대표권 관련 자료 검토 |
| 의뢰자 | 개별 종중원 또는 종중. 접수 시 의뢰 주체와 자료 제공 권한 확인 |
| 관련 종중원 | 총무 [이정호](../../familly/이정호.md), 분쟁 경험이 있는 [이상훈](../../familly/이상훈.md) |
| 디지털 업무 | PC로 서류 접수, 보완 요청, 변호사 검토와 의견 전달 |
| 서비스 접근 | 의뢰별 담당자 계정과 업무 권한. 사무소 공용 계정을 쓰지 않음 |

## 현재 행동과 불편

상담 전에 직원이 회의록을 받지만, 소집 자료나 당시 규약이 빠져 변호사가 검토를 시작하지 못하는 일이 있다. 전화로 요청한 보완 서류가 다른 직원에게 도착하면 어떤 의뢰의 자료인지 다시 확인한다.

직원이 파일을 확인했다는 표시와 변호사가 내용을 검토했다는 표시가 같으면 의뢰인이 의견 전달까지 끝난 것으로 이해한다. 담당 직원이 바뀔 때에는 개인 메신저에 남아 있는 요청 내역을 찾기 어렵다.

## 목표와 도입 조건

- 자료 접수, 보완 요청, 변호사 검토와 의견 전달을 단계별로 확인한다.
- 파일을 받은 직원과 의견을 작성한 변호사를 각각 기록한다.
- 자료 목록, 받은 버전과 빠진 서류를 의뢰 건에 모은다.
- 담당자 교체 시 업무 내역을 넘기고 이전 담당자의 접근을 종료한다.

대표 발언: “직원이 서류를 받은 것과 변호사가 검토한 것은 구분해서 보여줘야 해요. 보완 요청이 어디까지 진행됐는지도 함께 보고 싶습니다.”

## 서비스 사용 장면

이정호가 토지 처분 관련 상담 자료를 공유한다. 접수 직원은 파일 목록과 누락 사항을 확인해 보완을 요청한다. 담당 변호사는 준비된 자료의 버전을 검토하고 의견을 전달한다. 이후 정정된 회의록을 받으면 이미 검토한 자료와 새 자료를 구분해 다시 확인한다.

이상훈이 별도로 상담을 신청하면 종중 의뢰와 같은 건으로 합치지 않는다. 의뢰인과 수임 가능 여부를 확인한 뒤 각 의뢰의 공유 범위를 따로 정한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 접수와 검토 | 직원의 접수 완료가 변호사의 법률 검토 완료로 표시되지 않는다. |
| 자료 보완 | 요청 서류, 수신 여부와 검토할 버전을 의뢰별로 찾을 수 있다. |
| 개인 상담 추가 | 종중과 개별 종중원의 자료를 자동으로 합치거나 상호 공개하지 않는다. |
| 담당자 교체 | 새 담당자가 업무 내역을 이어받고 이전 담당자의 접근은 종료된다. |

## PRD 연결

P0의 문서 버전과 기록 근거를 활용하고, P1의 전문가 의뢰를 사무소 내 여러 담당자가 처리하는 흐름을 검증한다. 접수 직원의 업무와 변호사의 전문 검토를 구분하는 권한·상태 설계는 추가 확인 대상이다.
