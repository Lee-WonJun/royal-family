# 배수아

오래된 토지 처분 경위와 종중 기록을 대조하는 개인 변호사. 과거 자료가 여러 담당자에게 흩어져 있는 의뢰에서 문서의 출처와 순서를 정리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변호사 |
| 나이와 경력 | 52세, 재산 분쟁 업무 22년 |
| 활동 지역·상담 방식 | 광주·전라, 대면 상담과 우편·스캔 자료 검토 |
| 주된 분야 | 과거 토지 처분 경위, 회의 기록 불일치와 자료 정정 |
| 의뢰 조건 | 기억에 의한 설명과 보유 기록을 따로 제출 |
| 디지털 업무 | 종이 원본 설명을 스캔본·파일 목록과 함께 관리 |
| 서비스 접근 | 검토할 기간과 토지를 지정한 자료 묶음 |

## 현재 행동과 불편

전임 담당자가 보관한 회의록에는 빠진 페이지가 있고 새 담당자가 받은 파일에는 다른 작성일이 적혀 있다. 의뢰인의 기억과 문서 내용도 다를 수 있다. 최신 파일 하나만 받으면 언제 어떤 내용이 바뀌었는지 확인할 수 없다.

## 목표와 도입 조건

- 기록의 원본 보관자, 수집 경로와 누락 페이지를 확인한다.
- 사건 경위와 문서의 작성·등록·정정 시점을 나눠 정리한다.
- 의견에 사용한 자료 버전을 고정하고 후속 자료는 재검토 대상으로 남긴다.

자료를 정정할 때 이전본과 출처를 지우거나 AI가 추측한 경위를 사실로 채우는 방식은 받아들이지 않는다.

대표 발언: “새 파일만 주시면 예전 기록과 무엇이 달라졌는지 알기 어렵습니다. 처음 받은 자료부터 순서대로 보고 싶어요.”

## 서비스 사용 장면

[이태식](../../familly/이태식.md)이 오래된 파일철을 이관하고 [이상훈](../../familly/이상훈.md)이 기록의 불일치를 제기한다. 배수아는 보완 전후 파일과 당시 규약을 대조한다. 기억에 따른 설명은 별도 메모로 남기고 근거가 없는 내용을 확정하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 오래된 자료 | 원본 보관 정보와 누락 상태를 확인하며 스캔본을 자동으로 완전한 원본이라 표시하지 않는다. |
| 정정 대조 | 이전본·보완본과 정정 사유를 같은 흐름에서 찾을 수 있다. |
| 의견 기준 | 검토 뒤 자료가 바뀌면 기존 의견이 어떤 버전을 근거로 했는지 유지된다. |

## PRD 연결

토지 분쟁 경험을 자료 수집·정정 이력·전문가 검토의 연결 관점으로 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-09](../../../../docs/prd/hackathon-prd.md#rf-09), [RF-10](../../../../docs/prd/hackathon-prd.md#rf-10), [RF-18](../../../../docs/prd/hackathon-prd.md#rf-18).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
