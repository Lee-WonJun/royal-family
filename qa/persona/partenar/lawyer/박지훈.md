# 박지훈

토지 소유권과 종중 재산 처분 분쟁을 검토하는 개인 변호사. 의뢰인의 설명과 실제 기록을 대조하고, 누구를 위해 어떤 업무를 맡았는지 명확하게 정리해야 한다.

이름·나이·경력·경험과 대표 발언은 QA를 위한 가상 설정이다. 실제 전문가나 사건을 모델로 삼지 않았다. 종중원 10명과 별개의 외부 전문가이며, 전문가 연계는 PRD의 P1 검토 기능이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 전문가 |
| 나이와 경력 | 45세, 변호사 업무 13년이라는 가상 설정 |
| 주된 분야 | 토지 처분, 소유권, 종중 의결·대표권 관련 분쟁 상담 |
| 의뢰자 | 개별 종중원 또는 종중. 의뢰 건마다 구분 |

| 디지털 업무 | PC에서 PDF·원본 자료·사건 경위를 비교 |
| 서비스 접근 | 수임·공유 범위를 확인한 의뢰 건과 지정 서류에 한시적 접근 |

## 현재 행동과 불편

상담을 받으러 온 사람이 회의록 사진과 다른 사람의 설명만 가져오기도 한다. 회의록의 작성 시점, 소집 자료, 실제 참석 근거와 규약 버전을 추가로 요청해야 한다. 종중을 대표한다는 사람과 개별 종중원의 의뢰가 섞이면 상담 목적부터 다시 확인한다.

서비스에서 ‘확인 완료’라고 표시한 문서도 누가 어떤 내용을 확인했는지 알아야 판단에 사용할 수 있다. 수정된 최신본만 받으면 분쟁 당시 기록이 어떻게 달랐는지 파악하기 어렵다.

## 목표와 필요한 자료

- 의뢰 당사자, 요청 업무, 자료 제공자의 권한을 확인한다.
- 당시 규약, 소집 자료, 참석·위임 근거와 회의록 버전을 연결해 본다.
- 설명에 그치는 주장과 자료로 확인한 내용을 구분한다.
- 받은 자료의 목록과 시점, 추가 요청과 답변을 의뢰 건에 남긴다.

대표 발언: “종중 전체의 의뢰인지 한 종중원의 상담인지부터 확인하겠습니다. 같은 회의라도 보는 범위가 달라질 수 있어요.”

## 서비스 사용 장면

이상훈이 상담을 요청하며 특정 토지와 회의 기록을 공유한다. 박지훈은 접근 가능한 자료만 확인하고 빠진 근거를 요청한다. 새로운 회의록 버전이 추가되면 이미 검토한 버전과 구분해 다시 읽는다. 상담 종료 시 서비스 접근을 마치고, 별도 보관이 필요한 자료의 처리 방식은 의뢰 약정과 보유 기준에 따라 정한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 의뢰인 확인 | 종중과 개별 종중원의 의뢰를 구분하고 계정 직책만으로 대표권을 확정하지 않는다. |
| 기록 대조 | 회의록의 이전본·정정본과 근거 자료를 찾고 누락·미확인 항목을 표시할 수 있다. |
| 공유 범위 | 특정 상담을 받았다고 전체 종중 명부와 다른 사건 자료까지 접근할 수 없다. |
| 제출 상태 | 자료 준비, 상담, 실제 제출과 사건 결과를 다른 상태로 기록한다. |

## PRD 연결

P0의 기록 근거와 정정 이력, 문서 묶음을 검토하고 P1의 전문가 의뢰·한시적 공유를 검증한다. 소송의 진행이나 결과를 서비스가 자동으로 결정하는 흐름은 대상이 아니다.

근거 문서: [PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md)의 토지 분쟁 경험, 전문가 의뢰, 법률 검토가 필요한 경계.

직무 설정 참고: 소송 관련 행위와 일반 법률 사무를 규정한 [변호사법 제3조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0003&lsiSeq=290789&urlMode=lsScJoRltInfoR).
