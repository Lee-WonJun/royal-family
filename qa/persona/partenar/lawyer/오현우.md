# 오현우

토지 자료의 예상치 못한 변경을 처음 발견한 종중원의 초기 상담을 맡는 개인 변호사. 문의의 긴급성과 확인된 사실을 구분해 다음 확인 작업을 정리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변호사 |
| 나이와 경력 | 34세, 부동산 관련 법률 업무 5년 |
| 활동 지역·상담 방식 | 대전·충청, 자료를 먼저 받는 화상 상담 |
| 주된 분야 | 토지 자료 변경에 대한 초기 상담과 분쟁 자료 정리 |
| 의뢰 조건 | 변경 전후 자료, 조회 시점과 요청 목적 확인 |
| 디지털 업무 | 모바일 접수와 PC 원본 검토를 함께 사용 |
| 서비스 접근 | 상담 대상 토지와 연결된 회의·계약 자료에 한시적 접근 |

## 현재 행동과 불편

의뢰인이 알림 화면만 보고 땅이 넘어갔다고 단정하며 상담을 요청한다. 알림의 기준 자료와 최신 조회 자료를 확보했는지부터 확인해야 한다. 급하게 모은 캡처에는 파일 출처와 날짜가 잘려 있어 다시 요청하는 일이 많다.

## 목표와 도입 조건

- 자료가 실제로 달라진 항목과 아직 확인하지 못한 항목을 나눈다.
- 문의 접수 시점과 자료 확보·검토 시점을 기록한다.
- 상담에 필요한 원본과 회의·계약 자료를 짧은 목록으로 요청한다.

확인 실패나 첫 등록을 소유권 변동으로 안내하거나, 상담 요청을 긴급 조치 완료로 표시하면 사용을 중단한다.

대표 발언: “알림만으로 사건을 결론 내릴 수는 없어요. 어떤 자료의 무엇이 달라졌는지부터 확인하겠습니다.”

## 서비스 사용 장면

[이도윤](../../familly/이도윤.md)이 토지 변경 알림을 보고 상담을 신청한다. 오현우는 기준 자료와 새 자료의 출처·시점을 비교한다. 자료가 부족하면 확인할 질문을 남기고, 충분한 상담자료가 모인 뒤 후속 업무를 논의한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 변경 근거 | 첫 등록·확인 실패·자료 변경이 다른 상태로 보이고 기준 자료를 열 수 있다. |
| 긴급 문의 | 긴급 표시를 붙여도 법률 판단이나 외부 조치 완료로 자동 전환되지 않는다. |
| 원본 확보 | 캡처와 원본을 구분하고 빠진 자료와 추가 요청 내역을 찾을 수 있다. |

## PRD 연결

토지 자료 변화에서 상담자료 준비로 이어지는 추천 흐름을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-11](../../../../docs/prd/hackathon-prd.md#rf-11), [RF-18](../../../../docs/prd/hackathon-prd.md#rf-18).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
