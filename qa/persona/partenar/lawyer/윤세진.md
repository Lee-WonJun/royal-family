# 윤세진

종중 내부의 의견 충돌과 대표권 문제를 주로 맡는 개인 변호사. 같은 토지 자료를 두고 종중과 개별 종중원이 서로 다른 설명을 할 때 의뢰 주체부터 확인한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변호사 |
| 나이와 경력 | 47세, 단체 분쟁 자문 16년 |
| 활동 지역·상담 방식 | 서울·경기, 화상 상담 후 필요시 대면 |
| 주된 분야 | 종중 운영 갈등, 소집·위임·대표권 관련 쟁점 |
| 의뢰 조건 | 의뢰인과 관련 당사자, 요청 범위를 먼저 확인 |
| 디지털 업무 | 당사자별 설명과 동일 문서의 버전을 PC에서 대조 |
| 서비스 접근 | 맡은 의뢰의 지정 자료만 열람 |

## 현재 행동과 불편

회장과 일반 종중원이 각각 자신이 정당한 의뢰인이라고 설명한다. 같은 회의록도 서로 다른 쪽에 유리한 부분만 전달해 상담 전에 경위를 다시 묻게 된다. 누가 공유한 자료인지와 어느 시점의 규약인지 빠지면 쟁점을 정리하기 어렵다.

## 목표와 도입 조건

- 상담을 신청한 사람, 대표하는 대상과 자료 제공 권한을 확인한다.
- 서로 다른 주장에 근거 문서와 확인 상태를 연결한다.
- 추가로 확인할 질문을 당사자별로 정리한다.

의뢰가 다른 두 당사자의 문서를 같은 사건이라는 이유로 자동 공개하는 서비스에는 자료를 맡기지 않는다.

대표 발언: “누가 맞는지부터 고르지 말고, 누가 무엇을 의뢰했는지와 어떤 자료가 있는지 먼저 보여주세요.”

## 서비스 사용 장면

[이상훈](../../familly/이상훈.md)이 자신의 참석 기록에 대한 상담을 신청한다. 윤세진은 공개된 자료와 본인이 공유할 수 있는 기록을 확인하고 빠진 근거를 요청한다. 같은 종중의 회장 측 문의가 들어와도 별도 의뢰로 접수해 수임 검토와 공유 범위를 다시 확인한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 의뢰인 분리 | 같은 종중에 속한 두 신청자의 의뢰와 자료가 자동으로 합쳐지지 않는다. |
| 주장 비교 | 발언과 문서로 확인한 사실을 구분하고 출처가 없는 주장은 미확인으로 남긴다. |
| 대표권 확인 | 계정의 회장 표시만으로 종중을 대표하는 수임이 성립한 것으로 처리하지 않는다. |

## PRD 연결

대표권과 기록 근거를 확인하는 상담 후보로 전문가 추천·상담자료 준비를 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
