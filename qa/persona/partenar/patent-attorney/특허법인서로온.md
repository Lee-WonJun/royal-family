# 특허법인서로온

여러 변리사가 한 기술 검토에 참여하는 특허법인. 관련 자료를 공동 검토하되 다른 의뢰의 기술이나 고객 기록과 섞이지 않도록 관리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 특허법인의 담당팀 |
| 구성 | 변리사 4명, 기술 자료 담당자 2명 |
| 활동 지역·상담 방식 | 서울·대전, 화상 상담과 담당팀 협업 |
| 주된 분야 | 서비스 기술과 상표의 지식재산 검토 |
| 대표 담당자 | 책임 변리사 공지후 |
| 의뢰 조건 | 의뢰 주체·참여팀·자료 공유 범위를 확인 |
| 디지털 업무 | 내부 검토 메모, 의뢰인용 의견과 자료 버전 관리 |
| 서비스 접근 | 법인 소속과 의뢰별 배정을 별도로 확인 |

## 현재 행동과 불편

여러 검토자가 서로 다른 버전의 기술 문서를 읽으면 추가 질문이 겹친다. 내부 메모가 의뢰인용 의견과 같은 목록에 있으면 초안이 최종 결과로 전달될 수 있다. 같은 운영사의 별도 제품 의뢰도 자료 범위를 따로 정해야 한다.

## 목표와 도입 조건

- 팀이 사용할 기준 자료와 검토 버전을 맞춘다.
- 내부 의견과 책임자가 확인한 전달본을 구분한다.
- 검토가 끝난 팀원의 접근과 새 자료 공유를 종료한다.

법인 계정에 들어왔다는 이유로 모든 기술 의뢰가 보이거나 초안을 자동으로 고객에게 전달하는 서비스는 사용하지 않는다.

대표 발언: “같이 검토해도 누구나 모든 기술 자료를 보는 건 아닙니다. 전달할 의견과 내부 메모도 나눠야 해요.”

## 서비스 사용 장면

공지후가 운영사의 기술 상담에 담당팀을 배정한다. 팀은 지정 자료를 대조하고 추가 질문을 한 목록으로 정리한다. 책임자가 확인한 의견만 의뢰인에게 전달하며 다른 제품의 자료와 종중 운영 기록은 공유 대상에서 제외한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 팀 배정 | 미배정 변리사·직원은 해당 의뢰의 기술 자료를 열 수 없다. |
| 전달본 | 내부 초안과 확인된 의견서의 공개 범위가 다르다. |
| 공유 종료 | 종료한 담당자는 새로 추가된 문서에 접근하지 못한다. |

## PRD 연결

변리사 조직 연계의 팀 권한과 문서 버전 검증에 사용하는 확장 페르소나다. 실제 계약·제휴·출원 완료를 뜻하지 않는다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
