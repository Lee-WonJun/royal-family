# 특허사무소새온

상표와 기술 문의를 변리사에게 나눠 전달하는 특허사무소. 접수 직원이 필요한 자료를 먼저 확인하고 전문 검토는 배정된 변리사가 맡는다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 특허사무소 |
| 구성 | 변리사 2명, 접수·문서 직원 3명 |
| 활동 지역·상담 방식 | 서울·인천, 화상·대면 상담 |
| 주된 분야 | 상표와 소프트웨어 관련 지식재산 상담 |
| 대표 담당자 | 변리사 서주원·진예서 |
| 의뢰 조건 | 브랜드 문의와 기술 문의를 분류해 담당자 배정 |
| 디지털 업무 | 부족한 자료 요청과 분야별 검토 상태 관리 |
| 서비스 접근 | 배정된 건에 필요한 브랜드·기술 자료만 접근 |

## 현재 행동과 불편

고객이 변리사와 법무사를 혼동해 토지 등기 서류를 보내는 일이 있다. 직원이 받은 문의를 잘못 배정하면 전문가는 자료를 다시 요청해야 한다. 상표 문의와 기술 문의도 같은 상태로 관리하면 어느 검토가 끝났는지 알기 어렵다.

## 목표와 도입 조건

- 문의 목적을 접수 단계에서 확인해 분야별로 나눈다.
- 직원 접수와 변리사의 검토를 다른 상태로 남긴다.
- 담당자별 필요한 자료만 공유한다.

잘못 들어온 토지 서류가 사무소 전체에 자동 공개되거나 직원의 접수를 전문 검토 완료로 표시하면 사용하지 않는다.

대표 발언: “상표 상담인지 기술 상담인지부터 나눠주세요. 땅 등기를 문의한 자료는 담당 분야를 다시 확인해야 합니다.”

## 서비스 사용 장면

운영사가 상표와 기술 두 가지 상담을 신청한다. 접수 직원은 목적과 자료를 나눠 서주원과 진예서에게 배정한다. 토지 등기 문의가 들어오면 제출된 민감 자료를 확대 공유하지 않고 업무 분류를 다시 확인한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 잘못된 문의 | 토지 등기 문의를 변리사에게 자동 수임된 것으로 표시하지 않는다. |
| 분야별 상태 | 상표·기술 검토의 담당자와 진행 상태가 각각 유지된다. |
| 직원 권한 | 자료 접수 담당자는 전문 검토 결과를 대신 확정할 수 없다. |

## PRD 연결

조직 단위 변리사 후보를 추가할 때 분야 배정과 접수·검토 권한을 검증한다. 지식재산 지원은 사용자의 추가 요청에 따른 확장 검토 대상이다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
