# 배준서

기존 상표·특허와 관련된 자료를 검토하는 개인 변리사. 운영사가 보유한 권리와 외부에서 받은 설명을 구분하고, 추가 자문이 필요한 쟁점을 정리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변리사 |
| 나이와 경력 | 50세, 지식재산 업무 20년 |
| 활동 지역·상담 방식 | 부산·경남, 대면 상담 후 자료 검토 |
| 주된 분야 | 상표·특허 관련 권리 자료와 사용 목적 검토 |
| 의뢰자 | 서비스 운영사 또는 관련 권리 자료를 가진 사업 담당자 |
| 의뢰 조건 | 권리 종류·관련 당사자·검토 자료 범위 확인 |
| 디지털 업무 | 권리 자료와 의뢰인의 설명을 별도 항목으로 대조 |
| 서비스 접근 | 해당 지식재산 의뢰의 지정 문서 |

## 현재 행동과 불편

상표나 특허가 있다는 설명만으로 자유롭게 사용할 수 있다고 기대하는 의뢰인이 있다. 권리 자료의 시점과 관련 주체를 확인해야 하지만 전달받은 이미지에는 일부만 보인다. 계약 전체에 관한 질문이 함께 들어오면 자신의 담당 분야와 별도 법률 검토를 나눠야 한다.

## 목표와 도입 조건

- 보유 권리 자료의 출처·시점과 확인 상태를 남긴다.
- 확인한 자료와 의뢰인이 말한 내용을 구분한다.
- 지식재산 검토와 다른 분야의 법률 질문을 분리한다.

파일 하나를 올렸다는 이유로 권리 보유·사용 가능·계약 검토가 모두 완료된 것으로 표시하면 도입하지 않는다.

대표 발언: “권리가 있다는 말과 지금 어떤 용도로 쓸 수 있는지는 따로 확인해야 합니다. 받은 자료부터 대조해보죠.”

## 서비스 사용 장면

운영사가 이전에 확보한 상표 관련 자료와 새로운 사용 계획을 보낸다. 배준서는 자료의 내용과 의뢰 주체를 확인해 검토 질문을 정리한다. 계약 전반이나 토지에 관한 질문은 별도 전문가 검토 대상으로 남긴다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 자료 시점 | 오래된 권리 자료와 현재 확인 자료의 시점을 구분한다. |
| 판단 범위 | 문서 등록을 권리 보유나 사용 가능 확정으로 표시하지 않는다. |
| 분야 연결 | 지식재산 범위를 벗어나는 질문을 동일 의뢰의 완료 답변으로 묶지 않는다. |

## PRD 연결

변리사 의뢰를 확장할 경우 자료 확인과 분야 분류의 경계를 검증한다. 현재 전문가 후보 추천 범위에 자동으로 포함되는 기능은 아니다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
