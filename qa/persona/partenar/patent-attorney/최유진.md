# 최유진

상표·특허 등 지식재산 업무를 맡는 개인 변리사. 서비스 이름과 기술에 관한 문의를 검토하며 토지 등기나 종중 재산 분쟁 의뢰와 업무를 구분한다.

이름·나이·경력·경험과 대표 발언은 QA를 위한 가상 설정이다. 실제 전문가와 관계없다. 변리사 추가 요청을 반영했으며 지식재산 업무는 현재 PRD의 종중 운영 범위를 넘어서는 별도 확장 후보이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 전문가 |
| 나이와 경력 | 38세, 변리사 업무 9년이라는 가상 설정 |
| 주된 분야 | 서비스 명칭의 상표 검토, 기술의 지식재산 상담과 출원 관련 업무 |
| 의뢰자 | 우선 서비스 운영사. 향후 종중 사업의 상표 수요가 생기면 별도 의뢰로 검토 |
| 토지 업무와 관계 | 토지 소유권·부동산 등기 업무 담당자로 배정하지 않는다. |
| 디지털 업무 | 사업·기술 설명과 지정 자료를 받아 검토 의견과 준비 항목 관리 |
| 서비스 접근 | 지식재산 의뢰의 기술·브랜드 자료에 접근. 종중 전체 명부나 토지 분쟁 자료는 기본 대상이 아님 |

## 현재 행동과 불편

의뢰인이 변리사와 법무사를 혼동해 토지 등기 신청을 문의하거나, 새로운 서비스 아이디어가 있다는 이유만으로 특허 등록이 가능하다고 기대한다. 서비스 이름을 확보하려는 것인지, 기술을 검토받으려는 것인지, 권리 침해에 관한 문의인지 먼저 확인해야 한다.

소프트웨어 기술이나 사업 설명을 전달받을 때 관련 없는 종중원 개인정보까지 포함되면 필요한 자료를 다시 요청한다. 담당자에게 보여주는 범위도 의뢰 건별로 정하고 싶다.

## 목표와 도입 조건

- 상표·기술·권리 관련 문의의 목적과 의뢰 주체를 확인한다.
- 토지 등기나 소유권 분쟁 문의는 적합한 담당 분야로 재분류한다.
- 기술·브랜드 자료만 받아 검토하고 민감 정보의 공유 범위를 제한한다.
- 상담, 출원 준비, 실제 출원, 심사 결과를 구분한다.

대표 발언: “땅의 등기를 문의하시는 거라면 담당 분야를 다시 연결해야 해요. 저는 서비스 이름이나 기술의 권리부터 검토하겠습니다.”

## 서비스 사용 장면

서비스 운영사가 명칭 검토를 의뢰한다. 최유진은 신청 목적과 필요한 브랜드 자료를 확인해 의견을 전달한다. 토지 등기 문의가 같은 창구로 들어오면 법무사나 부동산 법률 담당자에게 연결할 수 있도록 분류를 요청한다. 기술 검토를 맡아도 종중의 회의·명부 자료에 전체 접근하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 분야 혼동 | 토지 등기 문의를 변리사에게 자동 배정하지 않고 적합한 업무 분류로 수정한다. |
| 자료 공유 | 기술·브랜드 자료 공유와 종중 운영 기록 공유가 분리된다. |
| 결과 표시 | 상담·자료 준비를 출원 접수나 권리 등록 완료로 표시하지 않는다. |
| 기능 범위 | 지식재산 지원이 후속 검토 기능이며 초기 종중 운영 서비스의 확정 제공 범위가 아님을 확인한다. |

## PRD 연결

직접 연결되는 P0 요구는 없다. P1 전문가 신청의 업무 분류·한시적 공유 구조를 지식재산 의뢰까지 넓힐지 확인하는 페르소나다. 변리사 지원을 추가한다고 기존 PRD에 상표·특허 신청 기능이 자동으로 포함되지는 않는다.
