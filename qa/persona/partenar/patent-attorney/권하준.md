# 권하준

명칭과 상표 사용 계획을 먼저 듣는 개인 변리사. 서비스 운영사나 별도 사업을 검토하는 종중이 이름을 확보하고 싶다는 문의를 하면 사용 대상과 의뢰 목적부터 정리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변리사 |
| 나이와 경력 | 42세, 상표 관련 업무 12년 |
| 활동 지역·상담 방식 | 서울·경기, 화상 상담과 브랜드 자료 검토 |
| 주된 분야 | 명칭·표장 관련 상담과 상표 출원 준비 |
| 의뢰자 | 서비스 운영사 또는 별도 사업을 논의하는 종중 |
| 의뢰 조건 | 출원 주체와 사용할 상품·서비스 설명 확인 |
| 디지털 업무 | 명칭 후보와 사용 예시를 의뢰 건별로 비교 |
| 서비스 접근 | 브랜드 자료와 승인된 의뢰 설명에 제한된 접근 |

## 현재 행동과 불편

고객은 서비스 이름, 종중 이름과 법인 이름을 같은 등록으로 확보할 수 있다고 기대한다. 명칭 후보는 있어도 어느 주체가 어디에 사용할지 정하지 않은 경우가 많다. 사업 설명에 토지 서류가 섞여 들어오면 불필요한 자료를 다시 분리해야 한다.

## 목표와 도입 조건

- 등록하려는 권리와 사용할 명칭·표장의 목적을 확인한다.
- 의뢰 주체와 사용 범위가 미정인 항목을 질문으로 남긴다.
- 검토 의견과 실제 출원·등록 상태를 별도로 전달한다.

상담 요청만으로 이름을 확보했다고 안내하거나 관련 없는 종중 명부까지 기본 공유하면 사용하지 않는다.

대표 발언: “이름만 보내주시면 판단할 정보가 부족합니다. 누가 어떤 서비스에 쓸 이름인지부터 알려주세요.”

## 서비스 사용 장면

명문가 운영사가 이름 검토를 의뢰한다. 권하준은 서비스 설명과 표장 자료만 받는다. 종중 사업의 이름 문의가 추가되면 의뢰 주체와 사용 계획이 다른 건으로 분리하고, 토지 등기 문의는 해당 분야로 돌린다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 권리 구분 | 서비스 이름 검토·단체 정보 등록·토지 등기가 같은 업무로 합쳐지지 않는다. |
| 의뢰 주체 | 출원 주체가 미정이면 임의로 종중이나 운영사 명의를 지정하지 않는다. |
| 결과 표시 | 검토 의견을 출원 접수나 상표 등록 완료로 표시하지 않는다. |

## PRD 연결

변리사 분야를 추가할 때 문의 목적과 공유 자료를 분류하는 검증 후보이다. 현재 해커톤 PRD의 법무사·변호사 추천과 별도로 검토할 확장이다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
