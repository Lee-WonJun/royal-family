# 송은채

이미 활동해온 종중의 운영 자료와 규약을 정비하는 개인 변호사. ‘새로 설립한다’는 요청을 받으면 기존 조직과 현재 필요한 정비 업무를 먼저 확인한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 변호사 |
| 나이와 경력 | 44세, 단체 운영 자문 13년 |
| 활동 지역·상담 방식 | 경기·충청, 화상 인터뷰와 대면 자료 확인 |
| 주된 분야 | 기존 종중의 운영 체계·규약 정비 자문 |
| 의뢰 조건 | 기존 활동과 보유 문서, 요청 목적 확인 |
| 디지털 업무 | 기존 문서와 정비 초안의 변경 항목 대조 |
| 서비스 접근 | 초기 정비 대상 자료와 관련 회의 기록 |

## 현재 행동과 불편

오랫동안 운영해온 종중인데 규약 파일과 등록 관련 자료가 없다고 설립을 처음부터 해달라는 문의가 들어온다. 보유 서류가 없다는 것과 기존 조직이 없다는 설명은 구분해야 한다. 공통 규약으로 기존 관행을 덮어쓰면 구성원 이견이 남는다.

## 목표와 도입 조건

- 기존 활동과 자료의 보유·미확인 상태를 확인한다.
- 현재 규약과 새 정비 초안의 변경 내용을 비교한다.
- 미해결 운영 쟁점과 후속 등록 업무를 나눠 정리한다.

서류가 부족하다는 이유로 기존 단체를 없던 것으로 처리하거나 양식만 채워 설립 완료라 표시하면 사용하지 않는다.

대표 발언: “자료가 없다는 말과 종중이 없다는 말은 같지 않아요. 어떻게 운영해왔는지부터 함께 정리해보죠.”

## 서비스 사용 장면

[이영수](../../familly/이영수.md)가 종중 운영을 온라인으로 옮기며 설립 지원을 문의한다. 송은채는 [이태식](../../familly/이태식.md)이 보유한 자료와 기존 활동 설명을 확인한다. 정비 초안에는 변경 항목과 확인할 질문을 남긴다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 기존 조직 | 자료 미보유를 신규 단체 구성과 자동으로 동일 처리하지 않는다. |
| 규약 정비 | 공통 서식 적용 시 기존 규약·관행과의 차이를 확인할 수 있다. |
| 완료 경계 | 운영 자료 정비와 외부 등록·등기 완료를 다른 상태로 둔다. |

## PRD 연결

설립 준비 문의에서 기존 종중의 정비 목적을 분류하고 필요한 전문가 질문을 만드는 흐름을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-15](../../../../docs/prd/hackathon-prd.md#rf-15), [RF-17](../../../../docs/prd/hackathon-prd.md#rf-17).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
