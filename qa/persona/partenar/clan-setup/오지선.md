# 오지선

종중의 첫 온라인 자료 정리를 돕는 초기 이용 지원 담당자. 전화와 종이 서류를 주로 쓰는 운영자를 도우면서 전문가에게 물을 질문을 따로 모은다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 초기 이용 지원 담당자 |
| 나이와 경력 | 39세, 문서 정리·고객 지원 8년 |
| 활동 지역·상담 방식 | 충청 지역, 전화 안내와 사전 협의한 대면 지원 |
| 주된 업무 | 자료 목록 만들기, 파일 등록, 화면 사용과 인수인계 지원 |
| 전문 자격 | 법률 전문 자격을 가진 것으로 설정하지 않음 |
| 의뢰 조건 | 자료 보관자와 지원받을 업무·접근 범위 확인 |
| 디지털 업무 | 스캔 파일 분류와 입력 상태 확인 |
| 서비스 접근 | 지원 기간에 지정된 자료 등록 권한 |

## 현재 행동과 불편

총무는 어디서부터 정리할지 몰라 족보와 회의록을 한꺼번에 보낸다. 회장이 대신 계정을 만들어 달라고 요청하기도 한다. 입력 지원을 받았다는 이유로 명부나 규약이 법적으로 확인됐다고 생각하면 지원자가 업무 경계를 설명해야 한다.

## 목표와 도입 조건

- 보유·누락·미확인 자료를 구분해 초기 목록을 만든다.
- 앱 이용 지원과 전문가 검토가 필요한 질문을 나눈다.
- 지원 종료 시 자료의 출처를 유지하며 등록 권한을 종료한다.

고객 계정을 공유받아 대신 법적 동의를 하거나 지원자에게 종중 전체 권한을 요구하는 흐름은 맡지 않는다.

대표 발언: “파일을 정리하고 화면에 올리는 일은 도와드릴 수 있어요. 규약이나 구성원 판단은 전문가에게 확인할 질문으로 남기겠습니다.”

## 서비스 사용 장면

[이정호](../../familly/이정호.md)가 첫 자료 등록을 요청한다. 오지선은 서류 종류와 보관자를 확인해 파일을 분류한다. [이순자](../../familly/이순자.md)처럼 미가입자인 종중원도 명부에 남기되 계정 사용과 응답은 대신 확정하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 지원자 권한 | 파일 등록 지원이 대표자·종중원·응답자의 권한으로 확대되지 않는다. |
| 미확인 자료 | 읽기 어려운 서류나 최신 여부 미확인 규약을 자동 확정하지 않는다. |
| 지원 종료 | 등록자·출처는 유지되며 종료된 지원 권한으로 새 자료를 바꾸지 못한다. |

## PRD 연결

초기 자료 준비의 비법률 지원과 전문가 연결을 구분하는 페르소나다. 지원자가 설립·등록의 법적 판단을 대신하지 않는다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-01](../../../../docs/prd/hackathon-prd.md#rf-01), [RF-10](../../../../docs/prd/hackathon-prd.md#rf-10), [RF-15](../../../../docs/prd/hackathon-prd.md#rf-15).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
