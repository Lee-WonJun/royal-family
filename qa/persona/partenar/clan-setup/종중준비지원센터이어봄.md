# 종중준비지원센터이어봄

초기 자료 정리와 전문 검토를 단계별로 연결하는 지원 조직. 종중의 구성·운영 정비와 등록 관련 준비를 하나의 완료 표시로 묶지 않는다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 초기 준비 지원 조직 |
| 구성 | 변호사 1명, 법무사 1명, 자료 정리 담당자 2명 |
| 활동 지역·상담 방식 | 경기·충청, 화상 인터뷰 후 필요시 대면 |
| 주된 업무 | 요청 목적 분류, 자료 준비, 분야별 전문가 연결과 운영 이관 |
| 대표 담당자 | 운영 조율 담당 남소정 |
| 의뢰 조건 | 지원 업무·전문가별 위임 범위·공유 대상 확인 |
| 디지털 업무 | 자료 준비·전문 검토·신청 상태를 담당별로 관리 |
| 서비스 접근 | 단계별 담당자에게 필요한 자료만 공유 |

## 현재 행동과 불편

준비 모임은 상담 창구 하나에서 모든 설립·등록·등기 업무가 끝날 것으로 기대한다. 자료 정리 직원은 전문가가 검토한 범위를 알기 어렵고 전문가는 정리 중인 파일의 버전을 다시 확인한다. 운영 이관 시 미해결 질문이 사라지면 새 총무가 같은 문의를 반복한다.

## 목표와 도입 조건

- 지원 계약과 분야별 전문 업무를 나눠 설명한다.
- 각 단계의 담당자·검토 자료·남은 질문을 연결한다.
- 운영 공간에 검토 버전과 미해결 과제를 함께 넘긴다.

자료 수집만 끝나도 설립 완료를 표시하거나 조직 소속 직원 모두에게 전체 명부를 공유하면 서비스를 사용하지 않는다.

대표 발언: “창구는 하나여도 맡은 일과 완료 기준은 다릅니다. 다음 담당자가 남은 질문을 이어받을 수 있게 정리하고 싶어요.”

## 서비스 사용 장면

준비 모임이 상담을 신청하면 남소정이 목적과 자료 유무를 정리한다. 규약·구성원 관련 질문은 변호사에게, 담당 가능한 등록·등기 서류 문의는 법무사에게 연결한다. 자료 정리 직원은 승인된 파일을 등록하고 후속 운영자에게 준비 상태를 이관한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 단계별 담당 | 자료 정리·전문 검토·신청에 담당자와 완료 기준이 따로 표시된다. |
| 조직 공유 | 직원 전체가 자동으로 관계 자료와 모든 의뢰에 접근하지 않는다. |
| 운영 이관 | 검토 버전·미해결 질문·남은 신청 업무가 이후 운영 공간에 전달된다. |

## PRD 연결

초기 준비에서 운영 이관까지 이어지는 조직 후보를 검증한다. 여러 전문가가 참여해도 실제 자격·수행 범위·제휴는 별도 확인 대상이다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
