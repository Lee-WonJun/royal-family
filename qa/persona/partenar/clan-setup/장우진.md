# 장우진

초기 준비 모임의 등록·등기 관련 서류 문의를 구체화하는 개인 법무사. 요청을 확인한 뒤 자신이 맡을 준비 업무와 다른 전문가에게 확인할 항목을 나눈다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 법무사 |
| 나이와 경력 | 43세, 등기·등록 서류 관련 업무 11년 |
| 활동 지역·상담 방식 | 부산·경남, 대면 상담과 자료 목록 확인 |
| 주된 분야 | 초기 등록·등기 관련 신청 목적 확인과 서류 준비 |
| 의뢰 조건 | 요청 대상·담당 가능 업무·위임 관계를 확인 |
| 디지털 업무 | 필요 서류와 보유·보완·미확인 상태를 목록으로 정리 |
| 서비스 접근 | 선택한 준비 업무에 필요한 서류 |

## 현재 행동과 불편

‘종중 설립’이라고 접수됐지만 실제로는 등록 자료를 찾거나 토지 등기를 준비하려는 경우가 있다. 문의 유형을 정하기 전에 모든 서류를 받으면 고객의 준비 부담만 커진다. 양식에 이름을 넣었다고 신청까지 끝난 것으로 생각하는 고객도 있다.

## 목표와 도입 조건

- 단체 운영 정비, 등록 관련 준비와 토지 등기를 구분한다.
- 요청 업무에 필요한 서류만 단계별로 안내한다.
- 자료 준비와 실제 신청·완료 증빙을 별도로 남긴다.

모든 설립 문의에 동일한 필수 서류를 요구하거나 실제 가능 업무 확인 전에 접수 완료를 표시하면 도입하지 않는다.

대표 발언: “무엇을 신청하려는지 정해지면 필요한 서류도 줄일 수 있어요. 먼저 원하시는 업무부터 확인하겠습니다.”

## 서비스 사용 장면

준비 모임이 설립 지원을 문의한다. 장우진은 목적과 현재 보유 자료를 확인하고 담당 가능 범위를 검토한다. 필요한 서류를 준비 목록에 올리고 규약·구성원 관련 이견은 별도 법률 질문으로 남긴다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 목적 확인 | 불명확한 문의는 미분류 상태로 남고 추가 질문을 받을 수 있다. |
| 준비 목록 | 선택한 업무에 맞는 자료만 요구하고 공통 양식으로 일괄 확정하지 않는다. |
| 접수 근거 | 준비 완료와 실제 외부 신청·완료에 다른 증빙을 연결한다. |

## PRD 연결

요청 업무와 보유 서류에 맞춘 설립 준비 목록·법무사 후보 추천을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
