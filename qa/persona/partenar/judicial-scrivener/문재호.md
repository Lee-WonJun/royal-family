# 문재호

대표자 정보와 토지 등기 관련 신청 목적을 먼저 확인하는 개인 법무사. ‘종중 등기를 바꾸고 싶다’는 문의를 구체적인 서류 준비 업무로 나눈다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 법무사 |
| 나이와 경력 | 48세, 등기 관련 업무 14년 |
| 활동 지역·상담 방식 | 대구·경북, 대면 또는 자료 확인 후 전화 |
| 주된 분야 | 대표자 정보 정비와 등기·등록 신청 관련 서류 준비 |
| 의뢰 조건 | 변경하려는 대상과 신청 권한, 담당 가능 업무 확인 |
| 디지털 업무 | 회의 자료·대표자 자료와 보완 요청 목록을 대조 |
| 서비스 접근 | 해당 등록·등기 준비 업무에 필요한 자료 |

## 현재 행동과 불편

새 회장을 선출했다는 설명만으로 단체 정보와 모든 토지의 등기 정보를 함께 바꿔달라는 문의가 들어온다. 요청자가 말하는 변경 대상이 무엇인지 추가 질문이 필요하다. 대표자에 대한 이견이 있으면 단순 서류 준비와 법률 검토도 분리해야 한다.

## 목표와 도입 조건

- 단체 정보 정비, 등록 관련 업무와 토지 등기를 별도 요청으로 분류한다.
- 당시 회의와 규약 자료를 연결하고 미확인 항목을 남긴다.
- 본인이 맡을 업무와 다른 전문가에게 물을 질문을 구분한다.

회장 계정의 이름 변경을 외부 등록이나 토지 등기 완료로 표시하는 방식은 사용할 수 없다.

대표 발언: “화면의 회장 이름을 바꾸는 일과 밖에 신청할 일을 먼저 나눠야 합니다. 어느 자료를 바꾸려는 건지 확인해보죠.”

## 서비스 사용 장면

[이영수](../../familly/이영수.md)가 대표자 관련 정비를 문의한다. 문재호는 변경 대상과 보유 자료를 확인한다. 회의 과정에 이견이 있으면 법률 검토 질문을 남기고, 담당 가능한 신청 서류 준비와 외부 접수 상태를 따로 관리한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 변경 대상 | 계정 정보·등록 준비·토지 등기가 하나의 완료 상태로 묶이지 않는다. |
| 미해결 쟁점 | 대표자에 관한 이견을 해소된 것으로 처리하지 않고 전문가 질문으로 남긴다. |
| 업무 범위 | 가능 업무를 확인한 뒤 준비 목록을 만들고 다른 분야는 별도로 연결한다. |

## PRD 연결

설립·정비 문의의 업무 분류와 법무사 추천 근거를 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-15](../../../../docs/prd/hackathon-prd.md#rf-15), [RF-17](../../../../docs/prd/hackathon-prd.md#rf-17).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
