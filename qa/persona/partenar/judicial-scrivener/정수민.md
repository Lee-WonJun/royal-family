# 정수민

토지 등기와 등록 관련 서류를 검토하는 개인 법무사. 의뢰인이 말하는 ‘종중 등기’가 어떤 업무인지 구체화하고, 필요한 자료와 신청 상태를 정리한다.

이름·나이·경력·경험과 대표 발언은 QA를 위한 가상 설정이다. 실제 전문가나 사건과 관계없다. 종중원과 별개의 외부 전문가이며 서비스 연계는 P1 검토 기능이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 전문가 |
| 나이와 경력 | 49세, 법무사 업무 16년이라는 가상 설정 |
| 주된 분야 | 부동산 등기·등록 신청 관련 서류 준비와 검토 |
| 의뢰자 | 종중의 업무 담당자. 위임인과 신청 권한은 의뢰 건마다 확인 |
| 관련 종중원 | 총무 [이정호](../../familly/이정호.md), 전임 총무 [이태식](../../familly/이태식.md) |
| 디지털 업무 | 전자 문서와 스캔본을 대조하고 보완 요청을 관리 |
| 서비스 접근 | 해당 신청의 토지·회의·등록 자료에 제한된 접근 |

## 현재 행동과 불편

‘종중을 등기해달라’는 요청만 받아서는 등록번호 관련 업무인지, 대표자 정보 정비인지, 특정 토지의 소유권 등기인지 알기 어렵다. 오래된 규약과 등기권리 관련 자료를 받으면 최신 여부와 위임 관계를 추가로 확인한다.

서류를 한 번에 받지 못해 같은 자료를 여러 차례 요청하는 일이 번거롭다. 서비스상 문서 확인과 실제 신청 접수·완료가 같은 상태로 표시되면 의뢰인이 진행 상황을 오해할 수 있다.

## 목표와 필요한 자료

- 신청 목적과 토지·단체의 현재 자료를 확인한다.
- 요청 업무에 맞는 자료 목록과 보완 상태를 정리한다.
- 각 자료의 원본·사본 구분, 발급일과 확인일을 살핀다.
- 신청 준비, 접수, 보완, 완료 증빙을 각각 남긴다.

대표 발언: “‘종중 등기’라고만 하면 서류를 정할 수 없어요. 어떤 등록이나 토지 변경을 하려는지 먼저 확인해야 합니다.”

## 서비스 사용 장면

이정호가 토지 관련 신청을 의뢰하고 관련 회의록과 등기 자료를 연결한다. 정수민은 업무 종류를 확인해 필요한 자료를 요청하고, 이태식이 보관한 오래된 서류에는 최신 여부 확인을 남긴다. 실제 접수 뒤에는 접수 근거를 기록하며 완료를 확인할 자료가 준비된 시점에 완료 상태를 남긴다.

업무 수행 범위는 법무사 자격과 해당 신청에 적용되는 규정에 따라 확인한다. 토지 분쟁의 법률 판단이나 소송 대리를 하나의 등기 신청 업무로 묶지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 모호한 신청 | 업무 목적이 미정이면 추가 확인을 요청하고 모든 종중에 같은 신청 양식을 적용하지 않는다. |
| 서류 보완 | 빠진 자료, 최신 여부 미확인, 유효 기간 확인 필요를 구분한다. |
| 상태 전환 | PDF 준비나 전자서명만으로 등기 완료가 되지 않고 실제 접수·완료 근거를 연결한다. |
| 권한 종료 | 신청 완료 뒤 공유 기한이 끝나면 새 자료 열람이 차단된다. |

## PRD 연결

P0의 토지 자료·서류 보관·확인일을 활용하고 P1의 업무 유형 분류, 준비 서류, 신청 상태를 검증한다.

근거 문서: [PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md)의 토지 자료와 등기 변동 확인, 다음 출시 범위, 전문가 의뢰.

직무 설정 참고: 등기·등록 서류 작성과 신청 대리 등을 규정한 [법무사법 제2조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026297435).
