# 강민석

종이 서류를 오래 보관해온 종중의 토지 등기 자료 준비를 맡는 개인 법무사. 스캔본을 받아도 원본과 빠진 서류를 직접 확인하는 편이다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 개인 법무사 |
| 나이와 경력 | 62세, 등기 관련 업무 28년 |
| 활동 지역·상담 방식 | 전북·전남, 대면과 전화 상담 선호 |
| 주된 분야 | 보유 토지 등기 신청 관련 자료 확인과 서류 준비 |
| 의뢰 조건 | 신청 목적·위임 관계와 원본 보유 여부 확인 |
| 디지털 업무 | 출력한 자료를 검토하고 직원이 스캔 파일을 정리 |
| 서비스 접근 | 해당 토지 신청의 문서와 원본 확인 정보 |

## 현재 행동과 불편

서류를 휴대전화 사진으로 받으면 도장이나 뒷면이 빠져 다시 요청한다. 여러 토지의 자료가 한 파일에 섞여 있으면 어느 신청에 쓸 서류인지 분류해야 한다. 서비스의 자동 추출값보다 원문을 먼저 보고 싶다.

## 목표와 도입 조건

- 토지별 자료 목록과 원본·사본 상태를 한눈에 확인한다.
- 빠진 면과 읽기 어려운 페이지를 보완 요청으로 남긴다.
- 출력본에도 파일 버전과 준비 상태를 표시한다.

앱을 반드시 설치해야 하거나 화면에서만 검토할 수 있으면 기존 전화·종이 업무로 돌아간다.

대표 발언: “사진이 올라왔다고 서류가 다 갖춰진 건 아니에요. 원본이 있는지, 빠진 면은 없는지부터 봐야 합니다.”

## 서비스 사용 장면

[이태식](../../familly/이태식.md)이 보관 자료를 공유한다. 강민석은 토지별로 출력한 목록을 보고 누락 페이지와 원본 확인 요청을 남긴다. [이정호](../../familly/이정호.md)가 보완한 뒤 검토할 버전을 지정한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 종이 검토 | PDF 목록에 토지·문서 버전·원본 확인 상태가 함께 표시된다. |
| 누락 보완 | 앞면만 있는 자료나 불명확한 이미지가 준비 완료로 넘어가지 않는다. |
| 수동 연락 | 전화로 요청한 보완 내용도 요청자와 기록자를 구분해 남길 수 있다. |

## PRD 연결

법무사 추천에서 대면·전화 선호 조건과 원본 확인이 필요한 서류 준비를 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.

현재 기획: [해커톤 PRD](../../../../docs/prd/hackathon-prd.md)의 [RF-09](../../../../docs/prd/hackathon-prd.md#rf-09), [RF-15](../../../../docs/prd/hackathon-prd.md#rf-15).

배경 자료: [통화 기반 PRD 초안](../../../../rawdata/TTS/03_PRD_초안.md). 이 문서의 P0·P1은 원자료 단계의 구분이다.
