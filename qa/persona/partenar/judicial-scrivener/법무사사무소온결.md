# 법무사사무소온결

법무사와 직원이 지역 종중의 등기 자료 준비를 함께 처리하는 사무소. 전화로 자료를 받는 고객과 전자 자료를 보내는 고객을 같은 의뢰 목록에서 관리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 법무사사무소 |
| 구성 | 법무사 1명, 접수·문서 직원 3명 |
| 활동 지역·상담 방식 | 충청 지역, 전화·대면·전자 자료 접수 |
| 주된 분야 | 등기 신청 자료 준비와 누락 서류 보완 |
| 대표 담당자 | 법무사 조태건, 접수 담당 신예림 |
| 의뢰 조건 | 신청 목적과 위임 관계를 법무사가 확인 |
| 디지털 업무 | 직원별 자료 접수와 법무사 검토를 분리 |
| 서비스 접근 | 담당 업무에 필요한 의뢰 자료만 접근 |

## 현재 행동과 불편

고객은 지난번 통화한 직원에게 서류를 보냈다고 하지만 다른 직원은 받았는지 모른다. 직원을 거쳐 전달받은 설명과 원문도 엇갈린다. 자료 수신과 전문 검토를 같은 체크 표시로 관리하면 접수 직원에게 완료 문의가 몰린다.

## 목표와 도입 조건

- 접수 담당자와 전문 검토 담당자를 나눠 기록한다.
- 수신 파일과 보완 요청을 직원 교대 후에도 찾는다.
- 통화로 받은 설명과 원문 자료를 구분한다.

공용 계정 하나로 모두 작업하거나 직원의 수신 확인을 법무사의 검토로 표시하면 도입하지 않는다.

대표 발언: “오늘 다른 직원이 전화를 받아도 어떤 서류를 기다리는지 바로 알 수 있었으면 합니다.”

## 서비스 사용 장면

총무가 전화로 신청 준비를 문의하고 직원이 요청 자료를 정리한다. 받은 파일은 의뢰 건에 연결하며 조태건이 목적·위임 관계와 검토할 자료를 확인한다. 직원 교체 후에도 보완 요청이 유지되고 최종 검토자는 별도로 표시된다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 담당 구분 | 직원 접수와 법무사 검토에 다른 작성자·상태가 표시된다. |
| 교대 업무 | 담당 직원이 바뀌어도 누락 서류와 최근 답변을 찾을 수 있다. |
| 제출 구분 | 자료 수신만으로 실제 신청 접수나 등기 완료가 되지 않는다. |

## PRD 연결

조직 후보의 접수 방식과 다수 담당자의 서류 준비 흐름을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
