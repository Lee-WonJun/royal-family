# 법무사합동사무소이음터

두 법무사가 토지별 신청 준비를 나눠 맡는 합동사무소. 여러 지역에 토지를 보유한 종중의 의뢰에서 담당과 자료 범위를 토지별로 관리한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 법무사 합동사무소 |
| 구성 | 법무사 2명, 문서 담당 직원 2명 |
| 활동 지역·상담 방식 | 부산·경남, 화상 접수 후 업무별 현장·대면 확인 검토 |
| 주된 분야 | 여러 토지의 등기 신청 준비와 의뢰별 진행 관리 |
| 대표 담당자 | 법무사 구도현·양은서 |
| 의뢰 조건 | 토지별 요청 업무, 실제 수행 가능 지역과 위임 관계 확인 |
| 디지털 업무 | 토지별 준비 목록과 담당자를 비교 |
| 서비스 접근 | 배정된 의뢰·토지의 자료에 제한된 접근 |

## 현재 행동과 불편

종중에서 여러 필지의 서류를 한꺼번에 보내면 일부만 보완됐는데 전체가 준비됐다고 생각한다. 담당 법무사가 다를 때도 모든 자료가 같은 폴더에 있어 불필요한 문서까지 전달받는다. 한 신청의 완료가 다른 신청의 상태에 영향을 주면 재확인이 필요하다.

## 목표와 도입 조건

- 토지별 목적·담당자·누락 서류와 상태를 관리한다.
- 지역 안내와 실제 업무 가능 여부를 따로 확인한다.
- 중복 자료는 연결하되 각각의 검토 버전과 공개 범위를 유지한다.

한 토지의 검토 완료로 의뢰 전체가 완료되거나 모든 직원에게 전체 자료실을 여는 방식은 피한다.

대표 발언: “세 필지를 맡아도 준비가 끝난 건 하나일 수 있어요. 토지별로 무엇이 남았는지 보고 싶습니다.”

## 서비스 사용 장면

종중이 여러 토지의 자료를 보낸다. 이음터는 요청을 토지와 업무별로 나눠 구도현과 양은서에게 배정한다. 공통 규약은 지정 버전을 연결하고 각 토지의 보완 요청·준비 상태·실제 접수 근거는 따로 기록한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 토지별 상태 | 일부 토지의 준비나 완료가 다른 토지에 자동 적용되지 않는다. |
| 담당 범위 | 법무사별 배정과 공유 자료 범위를 확인하고 미배정 자료는 차단한다. |
| 지역 조건 | 활동 지역 안내만으로 수임 가능을 확정하지 않고 업무별 확인 상태를 남긴다. |

## PRD 연결

법무사 후보의 지역 조건과 여러 토지를 나눠 준비하는 흐름을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
