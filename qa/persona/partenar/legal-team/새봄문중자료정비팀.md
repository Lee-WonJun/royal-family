# 새봄문중자료정비팀

담당자가 바뀌는 시기에 오래된 서류를 정리하는 종중 내부 팀. 파일을 모으는 일과 전문가가 내용을 확인하는 일을 나눠 다음 운영자에게 넘긴다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 종중 내부 자료 정비팀 |
| 구성 | 현 총무, 전임 자료 보관자, 디지털 등록 담당자 등 3명 |
| 활동 지역·협업 방식 | 전북, 파일철 확인은 대면·후속 공유는 온라인 |
| 주된 업무 | 원본 목록·누락 페이지·규약 버전과 보관자 정리 |
| 대표 담당자 | 자료 정비 담당 이수경 |
| 전문 자격 | 팀 자체에 법률 전문 자격이 있다고 가정하지 않음 |
| 디지털 업무 | 스캔 자료와 종이 원본 설명을 함께 기록 |
| 서비스 접근 | 자료 이관 기간에 지정된 파일 등록·보완 권한 |

## 현재 행동과 불편

전임 총무의 PC와 파일철에서 같은 이름의 문서가 여러 개 나온다. 최신 여부를 모르는 규약도 있고 스캔본에는 빠진 페이지가 있다. 파일을 많이 올렸다는 이유로 정비가 끝났다고 표시되면 새 총무가 확인해야 할 질문을 찾기 어렵다.

## 목표와 도입 조건

- 문서의 보관자·출처·누락 상태를 남긴다.
- 정비 완료와 내용 검토 완료를 나눠 기록한다.
- 이관 뒤 남은 확인 과제와 접근 권한을 새 담당자에게 넘긴다.

오래된 자료를 삭제하고 최신본 하나만 남기거나 정리 담당자에게 전체 의결·공유 권한을 주는 방식은 피한다.

대표 발언: “파일을 다 올렸어도 확인할 건 남을 수 있어요. 다음 사람이 무엇부터 봐야 하는지 같이 넘겨야 합니다.”

## 서비스 사용 장면

이수경이 전임 담당자의 파일철을 등록한다. 읽기 어려운 문서에는 보완 요청을, 적용 시점을 모르는 규약에는 미확인 표시를 남긴다. 전문가에게 확인할 자료 묶음을 만든 뒤 이관 권한을 종료하고 출처는 유지한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 자료 출처 | 같은 제목의 자료라도 보관자·등록자·버전을 구분할 수 있다. |
| 미해결 이관 | 누락·미확인 과제가 이관 완료 뒤에도 후임에게 남는다. |
| 권한 종료 | 전임자는 종료된 이관 권한으로 문서를 수정할 수 없다. |

## PRD 연결

인수인계와 서류 정비 후 전문가에게 전달하는 흐름을 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
