# 해솔문중분쟁대응팀

토지 처분 기록에 이견이 생겼을 때 종중의 자료 요청과 상담 준비를 조율하는 내부 팀. 팀이 모은 사실과 당사자의 주장을 구분해 외부 전문가에게 전달한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 종중 내부의 상담 준비팀 |
| 구성 | 업무 조율자, 기록 담당자, 연락 담당자 등 3명 |
| 활동 지역·협업 방식 | 충청 지역, 대면 회의와 제한된 온라인 자료 공유 |
| 주된 업무 | 토지 분쟁 관련 기록 수집, 요청 이력과 전문가 질문 정리 |
| 대표 담당자 | 상담 준비 담당 이경호 |
| 전문 자격 | 팀이 법률 판단이나 소송 대리를 맡는 것으로 설정하지 않음 |
| 디지털 업무 | 회의·토지 자료를 시점별로 비교하고 답변을 기록 |
| 서비스 접근 | 확인된 위임과 업무 범위 안의 자료만 취급 |

## 현재 행동과 불편

같은 회의에 참석했다는 설명과 실제 기록이 다르다. 누군가는 회의록을 고쳐달라고 하고 다른 사람은 원본부터 보관하라고 요청한다. 팀 전체를 한쪽 당사자의 대리인으로 보는 오해도 생겨 누구의 자료를 어떤 목적에 모으는지 설명해야 한다.

## 목표와 도입 조건

- 정정 요청과 원본 보존을 함께 관리한다.
- 팀의 업무 범위와 외부 상담의 의뢰 주체를 명확히 남긴다.
- 당사자의 주장, 자료로 확인한 내용과 미확인 항목을 나눈다.

팀 이름만으로 모든 당사자의 자료 접근을 허용하거나 최신 회의록으로 이전 기록을 덮어쓰는 서비스는 사용하지 않는다.

대표 발언: “분쟁이 있다고 기록을 한쪽 설명으로 고치면 안 됩니다. 받은 자료와 요청 내역을 그대로 남기고 검토받고 싶어요.”

## 서비스 사용 장면

이경호가 토지 처분 안건의 기록 확인 요청을 모은다. 원본과 정정 요청을 나란히 보관하고 공유 권한을 확인해 상담자료를 준비한다. 개별 종중원의 별도 상담 내용은 종중 업무 자료에 자동으로 합치지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 정정 요청 | 요청 접수와 실제 정정을 구분하고 이전본을 보존한다. |
| 의뢰 범위 | 종중 상담과 개인 상담의 자료·답변이 자동으로 합쳐지지 않는다. |
| 사실 구분 | 의견·주장·확인 자료의 상태가 구분되고 불법 처분을 자동 확정하지 않는다. |

## PRD 연결

사용자가 중요하게 본 토지 분쟁 경험을 기록 보존과 상담자료 준비 관점에서 검증한다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
