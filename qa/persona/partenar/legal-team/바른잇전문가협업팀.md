# 바른잇전문가협업팀

변호사와 법무사가 함께 토지 관련 문의를 검토하는 외부 협업팀. 법률 쟁점 검토와 등기 서류 준비를 담당자별로 나누고 서로 필요한 자료만 전달한다.

이름·단체명·나이·경력·구성·지역·경험과 대표 발언은 모두 페르소나를 위한 가상 설정이다. 실제 전문가의 신원·자격·수임 가능성이나 실제 제휴를 나타내지 않는다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 형태 | 외부 전문가 협업팀 |
| 구성 | 변호사 1명, 법무사 1명, 의뢰 조율 담당자 1명 |
| 활동 지역·상담 방식 | 대전·충청, 화상 접수 후 업무별 대면 협의 |
| 주된 분야 | 종중 토지 관련 법률 질문과 등기 자료 준비의 협업 |
| 대표 담당자 | 변호사 서도경, 법무사 주하나, 조율 담당 홍인경 |
| 의뢰 조건 | 분야별 위임·수행 범위와 의뢰 주체를 확인 |
| 디지털 업무 | 담당별 질문·준비 목록·검토 버전 관리 |
| 서비스 접근 | 협업팀 소속과 무관하게 분야별 승인 자료만 접근 |

## 현재 행동과 불편

등기 서류 준비 도중 대표자나 의결에 대한 이견이 생기면 법률 검토와 준비 업무를 함께 추적해야 한다. 자료가 한 담당자에게만 가면 다른 담당자는 쟁점이 해결됐는지 모른다. 반대로 모든 파일을 공유하면 각 업무에 필요하지 않은 개인 상담까지 보게 된다.

## 목표와 도입 조건

- 법률 검토 질문과 서류 준비 업무를 별도 항목으로 유지한다.
- 분야별 담당자에게 필요한 근거와 확인 결과만 전달한다.
- 일부 업무 완료와 의뢰 전체의 남은 과제를 구분한다.

한 담당자가 확인했다고 다른 분야의 검토까지 자동 완료하거나 팀의 공용 계정으로 모든 의뢰를 열어주는 서비스는 쓰지 않는다.

대표 발언: “같이 맡는다고 같은 일을 하는 건 아니에요. 어떤 쟁점이 남았고 누가 다음 자료를 확인할지 보여주세요.”

## 서비스 사용 장면

홍인경이 토지 관련 신청 문의를 받는다. 주하나는 담당 가능한 서류 준비를 확인하고, 대표자 관련 이견은 서도경의 법률 검토 질문으로 남긴다. 서로 공유할 자료를 지정하고 각 결과를 확인한 버전에 연결한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 분야별 상태 | 서류 준비 완료가 법률 쟁점 해결이나 실제 등기 완료로 바뀌지 않는다. |
| 공유 범위 | 협업자가 필요한 자료만 전달받고 개인 상담 기록은 자동 공유되지 않는다. |
| 후속 과제 | 검토 결과와 남은 질문을 담당자·기준 버전과 함께 찾을 수 있다. |

## PRD 연결

업무 분류와 분야별 전문가 연결·자료 준비를 한 흐름에서 검증한다. 실제 통합 수임 상품이나 제휴가 존재한다는 뜻은 아니다. 현재 기능의 구현이나 실제 외부 접수 완료를 뜻하지 않는다.
