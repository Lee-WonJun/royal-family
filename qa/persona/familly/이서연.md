# 이서연

일과 돌봄 때문에 회의에 꾸준히 참석하기 어려운 종중원. 관심이 없는 것은 아니지만, 긴 자료를 읽거나 여러 번 연락을 주고받을 시간이 부족하다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 42세 |
| 종중 역할 | 일반 종중원, 회의에는 선택적으로 참석 |
| 생활 | 다른 지역에서 직장과 가족 돌봄을 병행 |
| 참여도 | 중요한 토지 안건은 확인하지만 일상 모임 참석은 적음 |
| 디지털 사용 | 모바일 서비스와 인증은 익숙하다. 종중 업무를 위해 PC를 켜는 일은 드물다. |
| 서비스 접근 | 본인 참석 응답·의견 등록, 허용된 회의와 자료 열람 |

## 현재 행동과 불편

메신저에 공지가 쌓이면 중요한 안건을 놓친다. 회의 자료를 읽기 전에 “참석할 거냐”는 질문부터 오면 내용을 모른 채 응답해야 한다. 참석하기 어렵다고 답한 것이 안건에 반대한다는 뜻으로 전달되는 것도 걱정이다.

회의가 끝난 뒤에는 결정 내용만 받기보다 어떤 선택지를 논의했고 어떤 근거로 결론을 냈는지 확인하고 싶다. 짧은 안내와 상세 자료가 함께 있어야 사용한다.

## 목표와 불편

- 안건, 관련 자료, 회의 일정과 자신이 응답할 일을 한 화면에서 찾는다.
- 참석 여부와 안건에 대한 의견을 각각 남긴다.
- 원문을 볼 수 있는 상태에서 간단한 안내를 먼저 읽는다.
- 잠깐 중단했다가 다시 열어도 본인의 응답 상태를 확인한다.

대표 발언: “회의에는 못 가지만 자료는 볼게요. 불참이라고 찬성이나 반대로 기록하면 안 돼요.”

## 서비스 사용 장면

퇴근길에 안내 링크를 열어 토지 활용 안건과 자료를 확인한다. 참석은 어렵다고 답하고, 비용과 활용 기간을 더 설명해 달라는 의견을 남긴다. 담당자가 답하면 회의 후 기록을 읽는다. P0의 참석 응답과 의견 수집이 정식 전자 의결 완료를 뜻하지 않는다는 점도 확인한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 모바일 안건 확인 | 원문 자료를 찾을 수 있고, 참석 응답과 의견 입력의 의미를 구분한다. |
| 불참 응답 | 불참이 찬성·반대·기권이나 실제 참석으로 자동 변환되지 않는다. |
| 재접속 | 인증 후 같은 안건에서 기존 응답을 확인하고 중복 입력 여부를 알아볼 수 있다. |

## PRD 연결

P0의 회의 상세, 참석 응답, 자료 열람과 모바일 안내를 검증한다. 짧은 안내에 대한 요구는 UX 가설이며, 안건과 원문을 확인하지 않아도 결정을 내리도록 설계하지 않는다.
