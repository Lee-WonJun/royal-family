# 이태식

오래된 종중 서류를 보관해 온 전임 총무. 기록의 배경을 잘 알지만, 정리되지 않은 원본을 온라인에 옮기는 일을 망설인다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 68세 |
| 종중 역할 | 전임 총무, 과거 규약·회의록·토지 서류 보관자 |
| 생활 | 종중 소재지 인근 거주, 현재는 공식 운영 업무에서 물러남 |
| 참여도 | 과거 안건이나 자료 확인이 필요할 때 참여 |
| 디지털 사용 | 스마트폰으로 사진을 촬영하고 보내는 데 익숙하다. PC 파일 분류는 자주 하지 않는다. |
| 서비스 접근 | 자료 이관 기간에 지정 자료 등록 권한. 기존 직책만으로 전체 운영 권한을 유지하지 않는다. |

## 현재 행동과 불편

서류는 연도별 봉투와 파일철에 보관한다. 제목이 비슷한 규약이 여러 장 있어 어느 것이 최종본인지 기억에 의존한다. 현 총무가 자료를 요청하면 필요한 부분을 휴대전화로 찍어 보내지만, 뒷면이나 첨부 페이지가 빠질 수 있다.

온라인에 올린 파일이 잘못 분류되거나 누군가 원본을 바꿔버릴까 걱정한다. 자료에 대한 설명을 남기고 원본과 새로 정리한 문서를 구분할 수 있으면 이관을 돕고 싶다.

## 목표와 도입 조건

- 종이 원본을 잃지 않고 자료의 출처와 보관 상태를 남긴다.
- 최신본인지 모르는 서류는 미확인 상태로 등록한다.
- 인수인계를 마치면 일상적인 운영 연락에서 벗어난다.
- 사진·스캔본과 이후 작성한 정리본을 같은 원본으로 취급하지 않는다.

대표 발언: “이게 마지막 규약인지 확실하지 않아요. 우선 올리되 확인 안 된 자료라고 남겨두세요.”

## 서비스 사용 장면

현 총무와 함께 기존 파일철을 살펴보고 자료를 등록한다. 일부 회의록에는 페이지 수와 원본 보관 위치에 대한 설명을 남긴다. 최신 여부가 불명확한 규약은 별도 검토를 요청한다. 인수인계가 끝나면 등록 권한을 종료하고 필요한 열람 범위만 남긴다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 불확실한 자료 등록 | 최신본 여부를 모르는 규약을 미확인 상태로 남기며, 서비스가 임의로 현재 적용 규약으로 지정하지 않는다. |
| 보완본 추가 | 빠진 페이지를 보완한 자료와 처음 등록한 파일을 구분하고 변경 사유를 찾을 수 있다. |
| 인수인계 종료 | 등록자와 출처는 유지되지만 종료한 이관 권한으로 문서를 수정할 수 없다. |

## PRD 연결

P0의 자료실, 규약 버전, 출처 정보, 담당자 인수인계를 검증한다. 초기 자료 정리 지원이 얼마나 필요한지 확인할 사용자다.
