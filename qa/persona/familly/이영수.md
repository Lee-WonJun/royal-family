# 이영수

종중 운영을 맡은 회장. 중요한 결정을 설명할 기록이 필요하지만, 오랫동안 해온 업무 방식을 한꺼번에 바꾸기는 부담스럽다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자를 모델로 삼지 않았다. 같은 가상 종중의 종중원 10명 중 한 명이다. 운영 권한과 법적 대표권의 확인 상태는 별도로 관리한다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 74세 |
| 종중 역할 | 회장, 서비스 도입을 제안하고 운영비 지출을 논의하는 사람 |
| 생활 | 은퇴 후 종중 소재지 인근에서 생활 |
| 참여도 | 정기 모임과 토지 관련 회의 대부분 참석 |
| 디지털 사용 | 스마트폰 통화·메신저·사진 확인은 익숙하다. 문서 편집과 인증 절차에는 도움이 필요하다. |
| 서비스 접근 | 운영 담당자 권한 후보. 권한 부여 근거와 승인 절차는 별도 확인 |

## 현재 행동과 불편

회의가 필요하면 총무에게 종중원 연락을 부탁하고, 준비된 종이 회의록을 읽어본다. 일부 구성원에게는 직접 전화한다. 총무가 정리한 서류를 믿고 맡기지만, 회의 뒤에 “나는 그런 내용을 들은 적 없다”는 말을 들으면 어떤 자료로 설명해야 할지 막막하다.

전임자에게 받은 서류와 현재 총무가 가진 서류가 서로 다른 경우가 있다. 자신이 모든 파일을 관리하기보다는 최종 기록을 쉽게 확인하고, 다음 회장에게 빠뜨리지 않고 넘기고 싶다.

## 목표와 도입 조건

- 안건을 누구에게 알렸고 누가 실제 참석했는지 확인한다.
- 회의록을 확인하기 전에 변경된 내용을 알아본다.
- 담당자가 바뀌어도 종중 기록을 계속 찾을 수 있게 한다.
- 종중원에게 설명할 수 있는 연간 비용과 업무 절감 근거가 있어야 도입을 제안한다.

대표 발언: “편해지는 건 좋은데, 나중에 왜 그렇게 결정했는지 보여줄 수 있어야 해.”

## 서비스 사용 장면

총무가 토지 활용 회의의 초안을 올린다. 이영수는 휴대전화에서 안건과 참석 기록을 확인하고 누락된 설명을 요청한다. 수정본이 오면 이전 내용과 비교한 뒤 해당 버전에 내부 확인을 남긴다. 종중원에게 나눠줄 문서 묶음은 PDF로 출력한다.

한 번 누르면 법적인 절차가 모두 끝난다고 생각할 수 있으므로, 내부 문서 확인과 별도로 검토해야 할 절차를 이해하는지 확인한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 초안 검토 | 모바일에서 안건·실제 참석·미확인 항목을 찾고, 미완성 문서를 최종본으로 오인하지 않는다. |
| 확인 후 정정 | 회의록이 바뀌었음을 알아보고 자신이 확인한 이전 버전과 변경 사유를 다시 찾는다. |
| 임기 종료 | 후임 담당자에게 운영 권한을 넘긴 뒤 기존 기록은 유지되고 본인의 변경 권한은 설정대로 조정된다. |

## PRD 연결

P0의 회의록 검토, 문서 버전, PDF 출력, 담당자 인수인계를 검증한다. 중요한 결정의 책임을 서비스의 완료 표시로 대신하려는 기대가 생기는지도 살핀다.
