# 이정호

종중의 연락과 서류를 실제로 처리하는 총무. 서비스 도입의 실무 담당자이며, 같은 정보를 여러 번 입력하는 일이 줄어들어야 계속 쓴다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 59세 |
| 종중 역할 | 총무, 명부·안내·회의록·첨부 서류 관리 |
| 생활 | 자영업을 하며 영업이 끝난 뒤 종중 업무 처리 |
| 참여도 | 회의 준비부터 사후 정리까지 담당 |
| 디지털 사용 | PC 엑셀과 파일 저장은 익숙하다. 복잡한 협업 도구나 권한 설정은 낯설다. |
| 서비스 접근 | 명부·회의·서류 작성 권한. 회의록 검토자는 별도로 둔다. |

## 현재 행동과 불편

명부는 엑셀, 참석 응답은 메신저, 전화 안내 결과는 수첩에 남긴다. 회의가 끝나면 이 내용을 다시 모아 회의록을 만든다. 이름이 비슷한 종중원이나 오래된 연락처 때문에 대상자를 확인하는 데 시간이 든다.

회장에게 설명할 최종 자료를 준비하면서도 가게 일을 해야 한다. 모든 종중원의 앱 가입을 기다리는 방식이라면 업무가 더 늘어난다고 느낀다. 대신 기존 자료를 옮기고 전화 응답도 함께 기록할 수 있으면 사용할 의향이 있다.

## 목표와 도입 조건

- 명부를 한 번 정리해 다음 회의에도 사용한다.
- 안내 실패, 미응답, 참석 예정, 실제 참석을 구분한다.
- 회의에 연결된 문서를 한 번에 찾아 출력한다.
- 잘못 입력한 기록은 고치되 원래 기록과 정정 이유를 남긴다.

대표 발언: “가입 안 한 사람까지 내가 연락해야 해. 화면에 없는 사람이라고 빼면 안 돼.”

## 서비스 사용 장면

기존 명부를 옮겨 연락처 확인 상태를 정리한다. 토지 관련 회의의 대상 목록을 확인하고 안내를 보낸다. 문자 발송이 실패한 종중원에게 전화한 뒤 통화 결과와 기록자를 남긴다. 회의 당일에는 참석 예정 목록을 바탕으로 실제 참석을 따로 기록한다.

초기 명부 입력이나 자료 이전 지원은 도입 요구로 확인하되, 엑셀 자동 가져오기를 이미 구현된 기능으로 가정하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 앱 미가입자 안내 | 계정이 없는 종중원도 대상에 포함하고 전화 안내의 방식·기록자·확인 근거를 남긴다. |
| 참석 변경 | 참석 예정자가 실제로 오지 않았을 때 실제 참석을 별도로 기록하고 잘못된 참석 처리로 이어지지 않는다. |
| 명부 정정 | 연락처를 고쳐도 이미 진행한 회의의 대상 목록과 안내 이력이 바뀌지 않는다. |
| 문서 묶음 출력 | 해당 회의의 회의록과 관련 토지 자료를 찾아 초안 상태가 드러나는 PDF를 만든다. |

## PRD 연결

P0의 명부, 회의 준비, 수동 안내, 실제 참석, 자료실과 PDF 출력을 검증한다. 입력 시간과 필수 자료 누락을 측정할 때 우선 관찰할 사용자다.
