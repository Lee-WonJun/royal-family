# 김미경

회의 기록의 검토를 맡는 종중원. 운영진의 설명을 믿는 것과 기록을 확인하는 일을 구분하며, 잘못된 내용을 찾았을 때 정정 과정도 남아야 한다고 생각한다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 63세 |
| 종중 역할 | 기록 검토 담당자 |
| 생활 | 사무직에서 은퇴했으며 정기 모임에 참석 |
| 참여도 | 회의 전 자료와 회의 후 기록을 꼼꼼하게 확인 |
| 디지털 사용 | PC 문서·PDF 비교에 익숙하다. 모바일은 알림 확인용으로 사용한다. |
| 서비스 접근 | 지정 회의의 자료 열람, 검토 의견, 특정 버전 확인 권한 |

## 현재 행동과 불편

회의록을 이메일로 받으면 파일을 따로 저장한다. 검토한 뒤 새 파일이 다시 오는데 수정한 부분이 표시되지 않아 처음부터 읽는다. 회의록에는 참석자가 있는데 이를 확인할 서명이나 다른 근거가 빠진 경우에도 별도 연락으로 확인해야 한다.

모든 개인정보를 열람할 필요는 없다. 회의 검토에 필요한 자료와 종중원 개인 연락처가 한꺼번에 공개되는 방식은 부담스럽다.

## 목표와 불편

- 이전본과 수정본의 차이, 수정자와 사유를 확인한다.
- 안건의 결론을 참석·응답·첨부 자료와 대조한다.
- 누락된 근거를 요청하고 검토가 끝나지 않은 부분을 남긴다.
- 검토 업무에 필요한 자료만 열람한다.

대표 발언: “제가 확인한 파일이 어느 버전인지 남겨주세요. 나중에 내용이 바뀌면 다시 봐야죠.”

## 서비스 사용 장면

총무가 검토를 요청한 회의록을 연다. 실제 참석 기록과 첨부 자료를 대조하고, 위임 자료가 없는 대리 참석 항목에 확인 의견을 남긴다. 총무가 수정하면 새 버전에서 의견이 어떻게 처리됐는지 확인한다. 기록 검토와 해당 결의의 법적 유효성 판단을 같은 승인으로 취급하지 않는다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 근거 자료 누락 | 누락된 자료를 발견하고 보완 요청을 남긴다. 근거가 없는 항목은 검토 완료로 조용히 넘어가지 않는다. |
| 완료본 변경 | 이전 확인 기록이 새 버전의 확인으로 재사용되지 않고, 확인한 버전을 다시 열 수 있다. |
| 접근 범위 | 검토 대상 회의의 자료는 볼 수 있지만 업무 범위 밖 연락처나 다른 종중 자료는 열람할 수 없다. |

## PRD 연결

P0의 검토 상태, 문서 버전, 권한, 변경 이력을 검증한다. 회의 대상자와 적용 규약이 당시 버전으로 유지되는지도 확인한다.
