# 김은지

종중 모임에 처음 본격적으로 참여하는 종중원. 서비스는 익숙하지만 종중 용어와 과거 기록을 모르기 때문에 무엇을 확인하고 응답해야 하는지 설명이 필요하다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화 참여자와 관계없다. 같은 가상 종중의 종중원 10명 중 한 명이며, 최근 운영 안내를 받기 시작했다는 설정이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 29세 |
| 종중 역할 | 일반 종중원, 운영 방식과 기록을 배우는 참여자 |
| 생활 | 다른 지역에서 직장 생활 |
| 참여도 | 과거 회의 참석은 거의 없고 최근 중요한 안건에 관심을 갖기 시작함 |
| 디지털 사용 | 모바일 문서·인증·웹 서비스에 익숙하지만 종중 용어와 등기 자료는 낯설다. |
| 서비스 접근 | 명부에는 있지만 계정 연결은 확인 대기. 앱 가입만으로 자료 전체를 공개하지 않는다. |

## 현재 행동과 불편

규약, 종중원, 위임, 의결 같은 말이 어떤 행동과 연결되는지 모른다. “서류를 보고 답하라”는 말을 들어도 최신 규약이 무엇이고 안건에 필요한 자료가 무엇인지 찾기 어렵다.

가입할 때 관계 자료나 개인정보를 많이 요구하면 꺼린다. 계정이 연결되지 않아 자료를 못 보는 경우에는 이유와 문의할 담당자를 알고 싶다. 질문이 많다는 이유로 참여 의지가 없는 사람으로 취급되는 것도 불편하다.

## 목표와 필요한 설명

- 최신 여부를 확인한 규약과 과거 결정의 배경을 찾는다.
- 참석 응답, 의견, 문서 확인의 차이를 이해한다.
- 명부 연결을 위해 필요한 정보와 검토 상태를 알아본다.
- 본인에게 공개되지 않는 자료의 이유와 담당자 연락 경로를 찾는다.

대표 발언: “가입은 했는데 어떤 자료를 보면 되나요? 확인 버튼이 동의한다는 뜻인지도 모르겠어요.”

## 서비스 사용 장면

안내 링크에서 계정을 만들고 명부 연결 검토 상태를 확인한다. 운영 담당자가 확인한 뒤 허용된 회의 자료를 열람한다. 용어 설명과 적용 규약의 버전을 보고 안건에 대한 질문을 남긴다. 가입, 명부 연결, 참석 응답을 각각 다른 상태로 이해하는지 확인한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 계정 연결 대기 | 자료 접근이 제한된 이유와 확인 담당자를 찾고, 새 계정이 다른 종중원 명부에 자동 연결되지 않는다. |
| 첫 안건 읽기 | 어떤 규약과 자료가 적용되는지 찾고, 문서 확인을 안건 찬성으로 오해하지 않는다. |
| 개인정보 입력 | 기본 명부에 불필요한 고유식별정보를 요구하지 않고, 관계 자료를 첨부하면 공개 범위를 확인할 수 있다. |

## PRD 연결

P0의 계정과 명부 분리, 접근 권한, 규약 열람과 UX 설명을 검증한다. 용어 안내는 설명 방식에 대한 제안이며 종중원 자격을 판정하는 규칙이 아니다.
