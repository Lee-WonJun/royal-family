# 김상훈

토지 처분 관련 회의 기록에 이의를 제기한 경험이 있는 종중원. 편리한 운영보다 원본 자료와 정정 이력을 직접 확인할 수 있는지를 먼저 본다.

이름·나이·직업·경험과 대표 발언은 제품 검증을 위한 가상 설정이다. 실제 통화에서 언급된 사건이나 인물을 재현한 것이 아니다. 같은 가상 종중의 종중원 10명 중 한 명이다.

## 기본 설정

| 항목 | 내용 |
| --- | --- |
| 나이 | 55세 |
| 종중 역할 | 일반 종중원, 토지 안건과 기록의 확인을 요구하는 사람 |
| 생활 | 직장 생활을 하며 분쟁 관련 자료를 개인적으로 정리해 본 경험 |
| 참여도 | 평소 참석은 선택적이지만 토지 처분·권한 변경 안건은 적극 확인 |
| 디지털 사용 | PC에서 PDF와 파일을 정리한다. 파일 출처·날짜·버전 확인에 익숙하다. |
| 서비스 접근 | 규약과 설정에 따른 자료 열람·의견 권한. 기록 수정 권한은 없음 |

## 가상 분쟁 경험

과거 토지 처분 안건의 회의록을 확인하다 자신의 기억과 참석 기록이 다르다는 점을 발견했다. 운영 담당자에게 안내 자료, 실제 참석 근거와 회의록 원본을 요청했지만 서로 다른 파일을 받아 정리하기 어려웠다. 이후 전문가 상담을 위해 받은 자료와 요청 이력을 모았다.

기록에 이견이 생긴 가상 상황이며, 사건의 법적 판단과 소송 결과는 미정이다. 제품 검증에서는 요청한 근거를 찾고 자료를 준비하는 과정을 살핀다.

## 목표와 신뢰 조건

- 누가 작성하고 확인한 어떤 버전인지 원본 자료와 함께 본다.
- 참석·위임 기록의 근거와 자신의 이의 제기 시점을 남긴다.
- 정정 후에도 이전 기록과 정정 이유를 찾는다.
- 상담이나 제출 준비에 필요한 자료를 허용 범위에서 묶어 내려받는다.
- 등기 자료의 마지막 확인일과 변동 내역을 확인한다.

대표 발언: “틀린 기록을 고치는 건 좋죠. 다만 전에는 뭐라고 적혀 있었고 왜 고쳤는지도 남아야 해요.”

## 서비스 사용 장면

토지 상세에서 연결된 회의록과 등기 자료를 찾는다. 본인의 참석 기록에 확인 요청을 남기고 관련 자료를 요청한다. 운영 담당자가 회의록을 정정하면 이전본과 새 버전을 비교한다. 필요하면 해당 회의의 문서 묶음을 PDF와 원본으로 내려받아 전문가 상담을 준비한다.

PDF 출력이 공증이나 증거의 법적 인정까지 보장한다고 기대하는지 살핀다. 전문가에게 자료를 공유하는 P1 기능에서는 다른 종중원 연락처 등 불필요한 정보가 함께 넘어가지 않아야 한다.

## 검증 시나리오

| 상황 | 관찰할 행동과 통과 기준 |
| --- | --- |
| 기록 이의 제기 | 본인이 확인한 기록 버전과 의견의 시점을 남기고 이후 정정 기록을 다시 찾을 수 있다. |
| 근거 확인 | 소집 자료·실제 참석·위임 자료·회의록을 연결해 찾고 근거가 없는 부분을 구분한다. |
| 자료 출력 | 선택한 회의와 토지의 버전·원본·목록이 일치하고 권한 밖 개인정보가 포함되지 않는다. |
| 전문가 공유 | P1에서 의뢰 건에 지정한 자료만 한시적으로 공유하며 전체 자료실 접근으로 확대되지 않는다. |

## PRD 연결

통화에서 중요하게 다룬 토지 분쟁 경험을 제품 검증 관점으로 연결한다. P0의 기록 근거, 정정 이력, PDF와 원본 출력, 등기 확인 상태를 검증하며 P1 전문가 공유의 범위도 확인한다.
