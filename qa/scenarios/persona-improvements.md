# 페르소나 개선 검수

[RF-23–RF-28](../../docs/prd/persona-improvements.md)을 검수한다. 전부 가상 데이터와 mock으로 실행하며 외부 AI·발송을 사용하지 않는다.

| 사례 | 기대 결과 |
| --- | --- |
| SC-35 간편 보기·예시 안내 | 세 묶음에서 상세 이동, 큰 글자, 예시 안내만으로 저장 없음 |
| SC-36 전화 설명·정정 | 버전 고정 설명서 한 장, 읽어준 응답 식별, 확인과 정정 이력 보존, 원응답 불변 |
| SC-37 빠른 응답 | 종원 선택, 핵심·기한·원문 버전, 미응답 우선, 저장 후 재방문 상태 유지, 만료·개정 응답 차단 |
| SC-38 근거·이의 | 당시 문서 버전과 참석 근거, 전후 변경·행위자·사유, 이의·답변 이력, 원문 불변 |
| SC-39 서류 보완 | 목적별 목록 차이, 메타데이터 검증, 자료 버전 연결, 요청→답변→확인, 남은 서류·미해결 요청 |
| SC-40 XLSX·오늘 업무 | 빈 이름·전화 앞자리 유실·중복·200행 초과 거절, 유효 행 선택, 원자적 반영, 반복 요청 중복 방지, 권한·가계 미추정 |

단위/PBT·빌드를 마친 뒤 전체 mock E2E와 독립 UI 검수를 실행한다. 모바일·태블릿·PC·가로 화면, 키보드, 확대, 초기화 이후 뒤늦은 결과를 검사하고 미확인 환경은 보고서에 남긴다.
