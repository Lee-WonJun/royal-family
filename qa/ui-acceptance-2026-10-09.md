# 독립 UI 검수

2026-10-09 · 검수 모델: GPT-6.1 Sol · 판정: **PASS**

구현 담당자의 자체 만족도 대신 별도 서브에이전트가 별도 Edge 탭에서 검수했다. 기준은 `rawdata/CandidateUi`의 홈·명부·회의 v2 이미지 3장과 사용자의 간결한 한국어·업무 흐름 요구다.

확인한 화면 폭은 1440·1280·768·360px와 가로 회전 800×360이다. 밝은 단색 구성, 사이드바, 제목·탭·행 위계, 3×2 업무 카드, 명부 목록·계층, 회의 목록·상세, 모바일 메뉴·설정·종원 상세·목록 복귀를 확인했다. 720px 재배치와 회전 후 검색값 유지도 확인했다.

| 발견한 결함 | 수정 후 확인 |
| --- | --- |
| 회의 초안이 원문 탭 안에 들어가고 초안 탭에 빈 상태가 표시됨 | 초안·원문·버전 이력 분리, 안건·논의·결정·미확인 항목 표시 확인 |
| 표 머리글·미가입 상태·보조 문구의 대비 부족 | 중요 회색 글자를 `#68717e` 등으로 조정하고 실제 렌더링 확인 |
| 모바일 명부의 숨김 접근성 레이블이 페이지 가로 넘침을 만듦 | 숨김 레이블 위치를 고정. 360px에서 문서 폭 345=345, 표 영역 305/580으로 내부 스크롤 확인 |

검수는 읽기와 화면 이동에 한정했다. 저장·리셋·실제 API를 실행하지 않았으며 제품 전체 E2E 합격이 아니다. 실제 브라우저 200% 확대는 도구가 지원하지 않아 미검증이다. React의 목록 key 경고는 남아 있지만 확인한 화면에서 렌더링 중단은 없었다.

## 시작 계정·개발자 코드 추가 검수

사용자의 추가 요청 후 같은 GPT-6.1 Sol 에이전트가 1440·360px에서 변경 화면을 재검수했다. 판정은 **PASS**다.

가상 인물 10명의 버튼·권장 시나리오, 이미경 선택 후 회의 기록 이동, 이서연 선택 후 동의 화면 이동, 프로필과 계정 변경을 확인했다. 계정 선택과 명부의 직책이 일치한다. 모바일에는 한 열로 표시되며 페이지 넘침이 없다.

잘못된 개발자 코드를 입력하면 짧은 오류를 표시하고 실제 호출 스위치 12개가 잠긴 상태를 유지한다. “입력코드는 개발자에게 직접 문의해 주세요.” 안내는 한 번만 표시한다. 실제 코드를 읽거나 정상 코드를 입력하지 않았고 실제 AI·업무 데이터 저장은 실행하지 않았다. 정상 코드·위조·만료·계정·세대 경계는 별도 서버 단위 테스트와 로컬 API 계약 확인에 해당한다.
