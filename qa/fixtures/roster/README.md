# 명부 가져오기 검수 파일

`import-review.xlsx`는 모두 가상인 3행을 포함한다. 첫 행은 등록 가능, 둘째 행은 숫자로 저장되어 앞자리 0이 사라진 연락처, 셋째 행은 이름 누락이다. 실제 연락처나 종원 자료가 아니다. 첫 시트의 미리보기에서 정상 1명·오류 2명을 표시하고 선택한 정상 행만 반영해야 한다.

사용자 입력 양식은 `service/public/templates/roster-template.xlsx`이며 예시 인물을 포함하지 않는다. 첫 시트는 입력 영역, 둘째 시트는 입력 안내다. 연락처는 텍스트 형식, 세대는 정수 형식이며 가져오기는 첫 시트만 읽는다.
