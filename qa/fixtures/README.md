- 회의·안내문·규약 검토본·거래·계약 준비·동의 요청은 모두 가상이다. 전사문은 직접 작성한 예시이며 실제 음성 전사 결과가 아니다. 음성 파일은 아직 없다.

- 전문가 이름은 가상 파트너 페르소나에서 가져왔다. 필터 시연용 지역·상담 방식·비용은 별도 가상 설정이며 실제 제휴·자격·가격·수임 가능성을 나타내지 않는다.
