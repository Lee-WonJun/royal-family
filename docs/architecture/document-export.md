# 선택 문서 PDF

RF-09의 내보내기는 서버에서 `documents.export-records`로 권한과 선택 버전을 확인한 뒤 PDF를 만든다. 기본값은 선택 문서 본문·상태·근거·미확인 항목이다. 원본 포함을 선택한 경우 해당 문서의 파일만 PDF 첨부로 넣고 목록을 표시한다. 다른 자료실 문서를 자동 포함하거나 외부로 전달하지 않는다.

- `/api/exports` POST는 선택한 문서 1–10개, 각 버전, 원본 포함 여부, 데이터 세대, 요청 키를 받는다. 파일 합계는 20MB까지다.
- 생성 파일은 현재 종중·세대의 R2에 SHA-256 키로 저장한다. 요청 키가 같은 재시도는 기존 내보내기를 반환한다. 파일 다운로드에서도 선택 범위와 세대를 다시 검사한다.
- PDF에는 제목, 버전, 상태, 기록 시각, 처리 구분, 정정 사유, 근거의 원문 위치, 미확인 항목, 첨부 목록, 시연 표시가 들어간다. 내부 열람용이며 법적 서명·승인·제출 완료를 나타내지 않는다.
- 직접 수정은 정정 사유와 새 버전을 만든다. 완료본을 덮어쓰지 않는다. 공식 법령·판례 사본은 서버에서 수정·승인을 차단하고 별도 검토 문서를 만들도록 한다.
- `pdf-lib`를 서버 런타임에서 사용한다. 한글 복합 글리프의 일부 누락을 피하려고 Pretendard 정적 폰트를 전체 삽입한다. 폰트의 SIL OFL을 함께 보존한다.

`test:pdf`는 선택 범위, 정확한 원본 첨부, 복수 페이지와 메타데이터를 검증한다. 3쪽의 긴 한글 fixture를 Poppler로 렌더링해 첫 페이지와 마지막 근거·첨부 페이지를 확인했다. 단위 검증은 실제 OpenAI 호출과 무관하다. 제품 전체 E2E는 최종 게이트에서 수행한다.

참고: [PDF-LIB의 폰트·첨부 API](https://pdf-lib.js.org/docs/api/classes/pdfdocument).

## 공식 근거 사본

2026-10-09에 국가법령정보센터에서 [민법 제275조](https://law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0275&lsiSeq=284415&urlMode=lsScJoRltInfoR), [제276조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1009073877)의 표시 시행일 `2026-03-17`과 [대법원 2025다213795](https://www.law.go.kr/LSW/precInfoP.do?precSeq=618205)의 선고일 `2026-02-26`을 확인했다. 조문 사본과 판결요지 정리에는 출처·날짜를 넣었다. 원격 검색이 완료되었다는 뜻은 아니며 AI가 입력으로 받은 사본의 기준일 이후 최신성을 보증하지 않는다.

기존 시연 기록은 보존하고 읽기 전용 공식 사본만 추가한다. 법령·판례 자료를 시연 종중의 실제 규약이나 실제 사건 기록으로 표시하지 않는다.
