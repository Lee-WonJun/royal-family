# 회의·회계·인수인계 기록

RF-04·05·06·10의 구현 계약. 현재 앱은 고정 시연 관리자로 동작하며 실제 종원 인증이나 법적 위임을 증명하지 않는다.

- 총회 생성 시 대상 명부와 안건 문서·규약의 버전을 저장한다. 정보 변경과 종원별 응답은 이전 버전의 전체 기록, 기록자, 시각을 남긴다. 과거 버전은 조회만 가능하다.
- 안내 결과, 읽음, 참석 예정, 실제 참석, 위임, 표결, 의견은 별도 필드다. 참석 예정·전화 안내·위임 기록으로 실제 참석이나 찬성표를 자동 생성하지 않는다. 미가입자도 생성 당시 명부에 포함된다.
- 표결에 미응답을 기록할 수 있으며 정족수·자격·가결 여부를 자동 판정하지 않는다. 위임에는 근거를 입력한다.
- 회계 정정은 원거래를 보존하는 대체 거래다. 정정 사유를 남기고 최신 거래만 합산한다. 이미 정정된 거래에서 별도 정정 갈래를 만들 수 없다. 증빙은 저장 당시 문서 버전을 참조한다.
- 인수인계는 기존 담당자를 열람 권한으로 바꾸고 선택 종원에게 해당 직책·관리 권한을 부여한다. 이관 내용·시각·입력자를 남긴다. 종원 ID, 가계 관계, 문서·회의·거래의 출처는 바뀌지 않는다. 현재 시연 계정 선택은 실제 역할별 인증과 별개다.
- 계약은 토지와 문서 버전에 연결하며 수정 전 내용·사유를 이력에 보존한다. 계약 기록 상태를 실제 체결·전자서명 완료로 사용하지 않는다.
- 토지 자료의 확인 대기·확인 지연·확인 실패는 마지막 성공 자료를 보존한다. 이 상태 변경만으로 소유자 변경 이벤트를 만들지 않는다.

검증은 `operations_test.cljs`의 독립 상태·이력 보존, 정정 연쇄의 금액 보존 PBT, 관리자 권한 종료와 자료 보존을 포함한다. 전체 시나리오 E2E는 최종 게이트에서 실행한다.
