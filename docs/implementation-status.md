# 1차 구현 현황

2026-10-09 · 전체 제품 완료 전

`service/`에 CLJS·UIx 화면, CLJS 업무 규칙, Vinext HTTP 연결 계층, D1·R2 저장 구조를 구현했다. 기본은 시연 관리자·mock이며 실제 API 호출과 ChatGPT Events는 아직 연결하지 않았다.

MCP 서버는 Events capability를 광고하지 않는다. 설정의 실제 호출 스위치는 모두 미연결 상태로 비활성화한다. 예시 초안과 고정 전사문을 실제 OpenAI 결과로 표시하지 않는다.

## 검증

- `npm run test:unit`: 14개 테스트, 25개 assertion 통과. PBT-01–07·10–14를 각각 100개 입력, seed `20261009`로 검사했다. 순수 업무 함수만 실행하며 외부 호출은 없다.
- `npm run typecheck`: 통과.
- CLJS UI·업무 ESM release 및 Vinext Worker 빌드: 통과. 브라우저 React와 서버 업무 번들을 분리했다.
- 로컬 D1 migration 적용, 홈·상태 API HTTP 200 확인.
- GPT-6.1 Sol 서브에이전트의 [독립 UI 검수](../qa/ui-acceptance-2026-10-09.md): PASS.
- 전체 E2E와 live 검증: 미실행. 필수 연동·시연 음성 등 [E2E 게이트](architecture/testing.md#e2e-gate)가 아직 충족되지 않았다. UI의 읽기·반응형 검수를 SC 전체 흐름 통과로 계산하지 않았다.

## 저장 구조

1차 시연 데이터는 D1 `workspaces`의 단일 종중 aggregate에 모듈별 JSON 구획으로 저장한다. 각 모듈은 자기 구획을 공개 함수로 갱신하고 앱 계층이 전체 revision·generation을 조건으로 원자적으로 저장한다. 원본 파일은 R2의 종중/데이터 세대별 키에 보존한다. 브라우저 저장소에 업무 원장을 두지 않는다.

동시 수정은 충돌로 반환하며 자동 덮어쓰지 않는다. 리셋은 DB 상태·모드를 seed로 복원하고 이전 세대 쓰기·파일 접근을 차단한다. 이전 R2 객체의 물리적 정리는 후속이다. 시크릿·원자료는 리셋 대상에 포함되지 않는다.

실행 명령은 [service/README.md](../service/README.md), 가상 데이터 구분은 [fixture 설명](../qa/fixtures/README.md)을 따른다. 비공개 사이트 배포와 실제 API·MCP·Events 연결 검증은 각각 별도 결과로 기록한다.
