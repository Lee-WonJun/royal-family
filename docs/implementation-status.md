Luna Decisions가 가상 후보 2명 전체에서 박지훈을 선택하고 Luna로 이유를 작성했다. 각 3회, 총 6개의 추가 모델 요청이며 Astra는 없었다. v4에서는 이름과 선택 후보의 이유를 표시하고 의도적인 후보 제한을 자료 누락으로 오인한 문구가 사라졌다. 이 작업의 전체 모델 요청은 실패 사례 포함 16회이며 Astra 0회다. 이 초기 검증 당시에는 추출·법률 설명과 Sol 생성 경로가 fake 검사 범위였다. 아래 배포본 검증에서 세 경로 모두 실제 호출을 확인했다. 모든 실제 호출 토글은 검증 후 OFF로 복원했다.
