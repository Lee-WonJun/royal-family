# 해커톤 제출 준비

2026-10-09 사용자 요청: 비동기 UX와 실제 OpenAI 연결을 포함해 제출 가능한 완성본까지 진행한다. `System oneshot` 표현은 사용자의 정정에 따라 **Luna와 Decisions**로 해석한다. 생성 모델은 **Luna Decisions가 `gpt-6-luna`와 `gpt-6.1-sol` 중 선택**한다. Astra는 사용자의 명시적 요청으로 제외한다. 녹음 전사는 `whisper-1`을 사용하며 모델의 입력 형식과 기능을 맞춘다. 라우팅 실패를 임의 모델 선택으로 우회하지 않는다.

## 완료 순서

1. 요청 상태·진행·실패·중복 방지와 입력 보존.
2. 서버 OpenAI 어댑터, 작업 상태 저장, Whisper·추출·File Search·초안·Decisions, 실행 증거와 검토 흐름.
3. PRD 필수 업무의 미완료 부분과 서비스 skills·MCP Events 구현.
4. 단위·PBT·보안·빌드 후 mock E2E. 선택한 소수 실제 API·ChatGPT 연결 사례 검증.
5. GPT-6.1 Sol 독립 UI 합격, 커밋·푸시·Sites 배포, 시연 순서와 제출 자료의 구현 상태 정합성.

현재 진행 기록은 [구현 현황](implementation-status.md)에 반영한다. 미연결 API, 외부 서비스 승인, 실제 채팅 수신 증거가 남아 있으면 완료로 기록하지 않는다. 제출 준비는 사용자를 대신한 법적 동의·서명·최종 제출을 뜻하지 않는다.

기능별 실제 호출은 개발자 코드와 ON 상태를 확인한다. 기본·일반 회귀 테스트는 mock이며 실제 실패를 mock 성공으로 바꾸지 않는다. 시크릿은 `vaults`와 서버 환경에만 둔다. 원자료와 다른 동시 작업은 보존한다.
