# 명문가 발표자료 디자인

## 기준

첫 초안의 종이색 배경과 깊은 청록을 기본으로 쓴다. 사용자가 v5에서 되돌린 도입부와 명문가 소개 화면을 기준으로 삼는다. 푸른 기운은 낮은 채도의 청록과 회청색으로 표현한다.

`Premium Cloud Widescreen Multicolored.pptx`는 픽토그램과 다이어그램의 참고 자료다. 원 안의 아이콘, 단계 연결, 포함 관계를 빌려 쓰되 템플릿의 무지개색과 회색 글씨를 전체 테마로 가져오지 않는다.

발표자가 설명한다. 슬라이드는 문장을 대신 읽어주는 화면보다 사진, 큰 숫자, 관계를 보여주는 그림에 가깝게 만든다.

## 색

| 용도 | 색 | 사용 위치 |
| --- | --- | --- |
| 기본 배경 | `#F5F2E9` | 내용 슬라이드, 도표 배경 |
| 기본 청록 | `#183E35` | 제목, 본문, 주요 숫자, 구분 슬라이드 배경 |
| 회청색 | `#567D89` | 비교 대상, SAM, 보조 아이콘 |
| 옅은 청록 | `#729690` | 세 번째 요소, 보조 영역 |
| 녹회색 | `#687568` | 출처, 날짜, 작은 설명 |
| 적갈색 | `#A85437` | 분쟁 사례, SOM, 제한된 강조 |
| 밝은 글씨 | `#F5F2E9` | 청록 배경 위의 제목과 픽토그램 |

밝은 배경에서는 청록을 주로 쓰고 비교가 필요한 요소만 보조색으로 구분한다. 한 화면에서 비슷한 의미의 요소에 다른 색을 임의로 붙이지 않는다. 사용자가 직접 고른 강조색과 사진 속 색은 유지한다.

## 글자와 문구

- 기본 글꼴은 **Noto Sans KR**다. 명문가 이름에는 **Noto Serif KR**, 큰 수치에는 **Calibri Light**를 쓸 수 있다.
- 16:9 화면을 유지한다. 현재 PPT의 실제 크기는 10 × 5.625인치다.
- 제목은 28~36pt, 항목 이름은 20~26pt, 큰 수치는 42~90pt를 기준으로 잡는다. 출처와 계산 가정은 11~13pt로 짧게 표시한다.
- 한 화면에서 전달할 내용은 하나로 정한다. 짧은 제목, 필요한 항목 이름, 숫자만 먼저 남긴다.
- `회의 녹음`, `동의 요청`, `재산 자료 비교`처럼 화면에 있는 일을 직접 쓴다. `혁신`, `새로운 시대`, `가치를 창출`, `완벽한 관리` 같은 설명 없는 수식은 추가하지 않는다.
- 사용자가 수정한 제목과 말투는 유지한다. 문구를 고칠 때는 의미를 넓히거나 구현 완료를 새로 주장하지 않는다.

## 픽토그램과 다이어그램

Lucide의 선형 아이콘을 기본으로 쓴다. 아이콘끼리 선 굵기와 실제 크기를 맞추고, 필요한 경우 청록 계열 원 안에 밝은 아이콘을 넣는다. 원은 항목을 묶는 용도로 쓴다.

| 내용 | 구성 |
| --- | --- |
| 업무 단계 | 픽토그램과 가로 화살표 |
| 시스템 구조 | 사용자가 보는 화면, 업무 모듈, 저장소와 AI의 연결 |
| 시장 범위 | 큰 원 안에 작은 원을 넣은 포함 관계 |
| 연도별 건수 | 0에서 시작하는 막대그래프 |
| 사례의 기간과 금액 | 큰 숫자와 단위, 출처별 짧은 이름 |

텍스트, 도형, 차트는 PPT에서 수정할 수 있도록 만든다. 전체 다이어그램을 이미지 한 장으로 굳히지 않는다. 그림의 크기가 수치에 비례하지 않을 때는 **포함 관계도, 면적 비례 아님**이라고 표시한다.

## 사진과 캡처

뉴스에는 실제 기사 제목이나 보도 화면을 사용하고 매체, 날짜, 원문 링크를 함께 남긴다. 뉴스의 생성 이미지를 실제 사건 사진으로 소개하지 않는다.

가족 대화 캡처는 종중 소개 제목 아래에 배치한다. 캡처의 원본 비율과 내용을 유지한다. 대화 속 주장이나 지도 표시를 소유권, 매각 면적, 피해 규모가 확인된 자료로 바꾸어 표현하지 않는다.

문구가 사진 위에 겹치지 않도록 여백을 확보한다. 사진을 줄여서 내용을 알아볼 수 없다면 제목을 옮기거나 사진이 차지하는 면적을 늘린다.

## TAM, SAM, SOM

사용자가 만든 중첩 원의 순서를 유지한다.

**TAM: 등록 종중 → SAM: 전담 관리 체계가 있는 종중 제외 → SOM: 3년 내 확보 목표**

‘사업형 종중’은 이 발표에서 **전담 인력과 관리 체계를 갖춘 종중**을 뜻한다. 임대료 수입이나 수익사업 여부만으로 제외하지 않는다. 임야, 농지, 대지, 건물 등 재산 종류도 제한하지 않는다.

### 계산 초안

| 항목 | 모수와 계산 | 연간 구독매출 환산 |
| --- | --- | --- |
| TAM | 등록 종중 237,071개 × 연 50만원 | 1,185.36억원 |
| SAM | 사업형 20% 제외 가정, 189,657개 × 연 50만원 | 948.29억원 |
| SOM | SAM의 1%를 3년 내 확보 가정, 1,897개 × 연 50만원 | 9.49억원 |

등록 종중 237,071개는 **2024년 6월 기준**의 등기법포럼 자료에 실린 국토교통부 조회 수치다. 모든 자연발생 종중이나 실제 구매 고객의 수는 아니다. [원문, 인쇄면 9쪽](https://ebook.kabl.kr/registrationforum/202409/11/)

사업형 종중의 전국 비중은 이번에 확인한 자료에서 집계하지 않는다. **20% 제외는 초안 가정**이다. 10%, 20%, 30% 제외 시나리오를 계산 파일에 함께 보존하고, 향후 종중 표본 조사로 바꾼다.

연 50만원도 명문가의 확정 요금이 아니다. 운영·관리 인접 서비스인 [ZUZU Fund Service](https://fundservice.zuzu.network/fund-pricing/)의 공개 요금을 참고한 계산 기준이다. VAT, 전문가 수임료, 일회성 설립비는 제외한다.

원 안에는 범위와 짧은 이름을, 옆에는 종중 수와 연간 금액을 놓는다. 등록 모수, 제외율, 구독료, 확보율을 섞어 하나의 확정 시장 통계처럼 표현하지 않는다. 자세한 출처와 계산은 발표자 노트와 [시장 계산 자료](data/market-estimate-v6.json)에 남긴다.

## 분쟁 관련 그래프

확인한 수치는 **국가법령정보센터 공개 판례 검색 건수**다. 전국에서 새로 발생한 분쟁이나 고유 사건 수를 측정한 통계가 아니다.

| 선고연도 | 검색 건수 |
| --- | --- |
| 2021 | 32 |
| 2022 | 37 |
| 2023 | 34 |
| 2024 | 23 |
| 2025 | 12 |

2026년 10월 9일, [국가법령정보센터](https://www.law.go.kr/precSc.do?menuId=7&query=%EC%A2%85%EC%A4%91)의 상세검색에서 판례본문 `종중`, 법원·사건대상 전체, 각 연도 1월 1일~12월 31일의 선고일자를 사용했다. 같은 사건의 심급이나 요약, 조세 사건이 포함될 수 있다. 공개 자료의 수록 범위도 연도마다 다를 수 있으므로 이 그래프로 분쟁이 줄었다거나 늘었다고 결론 내리지 않는다.

그래프 제목은 **종중 관련 판례, 선고연도별**로 쓴다. 축과 라벨에는 `검색 건수`를 표시한다. 기간 제한 없는 전체검색 결과 1,416건은 별도 수치로 표시하고, 최근 5년 합계와 섞지 않는다.

막대는 0에서 시작한다. 청록을 기본으로 쓰며, 수치를 막대 바로 위에 놓는다. 3D, 불필요한 범례, 장식용 눈금은 쓰지 않는다. 데이터와 조회 조건은 [연도별 검색 자료](data/precedent-year-search-20261009.json)에 남긴다.

## 수정 순서

사용자가 편집한 최신 PPT를 먼저 확인하고 복사본에서 작업한다. 사용자가 지운 문구나 슬라이드를 과거 생성본에서 다시 가져오지 않는다. 원본 이미지, 제목, 순서와 문구를 유지하면서 요청한 부분을 고친다.

내보낸 뒤에는 사진 배치, 중첩 원의 포함 관계, 그래프 값, 글자 잘림을 실제 렌더링으로 확인한다. 출처와 가정을 표시한 채로 최신 PPT와 미리보기를 함께 저장한다.
