# 명문가 종중 법령과 실제 판례 자료집

명문가의 종중 설립 준비, 총회·동의 기록, 재산 관리와 법률 근거 확인에 사용할 공식 자료다. **조회 기준일은 2026년 10월 9일**이며, 국가법령정보센터에서 법령 22종과 대법원 판례 25건의 공개 본문을 수집했다. 법률뿐 아니라 대통령령·대법원규칙·부령을 포함하며 판례에는 판결과 결정이 모두 있다.

종중 사건을 중심으로 모았고, 다른 비법인사단·일반 토지·제사주재자 관련 판례는 참고 범위를 별도로 표시했다. 공식 원문과 수집자의 요약·확인 질문을 구분한다. 전체 종중 법률자료를 망라한 자료집이나 특정 종중의 법률 검토 완료 기록은 아니다.

## 보관한 원문과 읽는 순서

`sources/2026-10-09/`와 `sources/2026-10-09-supplement/`에 공식 HTML 응답과 본문 추출 텍스트를 보관했다. 법령의 HTML은 해당 버전의 본문·부칙을 포함한다. 별표·별지서식의 별도 파일과 첨부 판결 PDF를 내려받은 것은 아니다. 판례 텍스트는 국가법령정보센터에 공개된 판시사항·판결요지·참조조문·전문을 보존하며, 원문에 없는 판결요지·환송 후 결과를 만들지 않았다.

법령은 선정 조문 → 당시 규약 → 관련 판례 → 사건 시점에 적용되는 연혁·부칙 순으로 대조한다. 판례는 판시사항과 요약을 찾은 다음 주문·이유·다수의견·별개/반대의견을 확인한다. 현행 법령의 시행일과 과거 판결의 선고일은 서로 다른 값이다.

서비스 검색에는 `catalog.json`의 출처 유형·법령 버전·선고일·조회일과 원문 위치를 함께 사용한다. `summary`, `limit`, `questions`는 수집자의 정리이며 공식 조문·판시사항과 같은 출처로 인용하지 않는다. 실제 종중 규약과 시연 데이터도 별도 출처 유형으로 유지한다. 현재 이 자료를 앱이나 OpenAI File Search에 색인한 상태는 아니다.

## 추가 수집과 갱신

원문 스냅샷은 덮어쓰지 않고 새 조회일의 폴더를 만든다. 새 법령·판례는 사건번호와 본문을 다시 확인한 뒤 카탈로그와 요약에 반영한다. 법령의 기본 조회 버전이 조회 기준일 이후 시행 예정이면 수집 스크립트는 그 항목을 실패로 남긴다. 이때 시행 중인 연혁 버전을 명시적으로 선택해야 한다.

[공식 원문 수집 스크립트](scripts/collect-official-sources.ps1)는 새 스냅샷 폴더만 허용한다. [자료집 생성 스크립트](scripts/build-catalog.ps1)는 확인된 최상위 수집 기록과 수집자 정리에서 목록·개별 문서·카탈로그를 재생성한다. [문서 검증 스크립트](scripts/verify-corpus.ps1)는 네트워크 없이 원문 해시·메타데이터·선정 조문·문서 링크를 확인한다.

사건 당시의 전체 연혁 법령, 등기예규·선례, 장사법 별표와 신청 서식, 공주시 조례·관할 기관 안내, 개별 세무 적용과 추가 최신 판례는 다음 수집 대상이다. 상담 준비에서는 누락된 자료와 기준일 이후 변경 여부를 먼저 확인한다.
