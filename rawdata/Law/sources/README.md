# 공식 법률 원문 스냅샷

이 폴더는 국가법령정보센터가 반환한 HTML과 그 본문에서 추출한 텍스트를 보관한다. 확인된 법령 22종과 판례 25건의 경로·해시는 상위 폴더의 [최종 수집 기록](../capture-manifest.json)에 있다. 검색·색인 대상의 식별은 [자료 카탈로그](../catalog.json)를 사용한다.

| 폴더 | 내용 |
| --- | --- |
| `2026-10-09/statutes` | 법령 20종의 버전 안내 HTML, 본문 HTML과 본문·부칙 추출 텍스트 |
| `2026-10-09/precedents` | 실제 판례 22건의 HTML과 공개 본문 추출 텍스트 |
| `2026-10-09-supplement/statutes` | 등록번호 규정과 시행규칙 2종 |
| `2026-10-09-supplement/precedents` | 정기총회 예외, 분묘기지권, 단순 채무부담 관련 3건 |
| `collection-attempts` | 초기 조회·정규화 과정의 응답과 중간 기록. 검색·색인 대상에서 제외 |

HTML은 수집 당시 응답을 수정하지 않은 원본이다. 텍스트는 태그와 화면 제어 요소를 제거한 파생 자료이며 별표·별지서식의 별도 파일을 포함하지 않는다. `.gitattributes`는 이 폴더의 파일을 Git 줄바꿈 변환에서 제외하여 다른 운영체제의 체크아웃에서도 원문 해시를 유지하도록 한다. 중간 기록의 실패나 예전 추출 텍스트 해시는 초기 시도에 관한 값이며, 최종 원문 검증 상태는 상위 폴더의 [검증 결과](../verification-result.json)를 따른다.
